## 已知边界

- 61条路由有直接UI采样；其余复用已有数据/公共控件，没有逐页像素一致证据。
- brandList 两次访问失败，按用户指令跳过；企业编辑仍缺明确展开形态的来源证据。
- 案例视频已观察但资源导出失败，没有伪造本地视频；图片资源与本地选择/预览按实际可用能力展示。
- 富文本为静态交互实现，未移植原站整个编辑器引擎，复杂浮层没有全面像素验收。
- 原站有意空字段保留为空；默认非空样本不能覆盖真实空/失败/权限状态含义。
- 未执行任何生产变更。本次发布校验另外记录，不将本机测试时间当作远端部署时间。

机器摘要见同目录 JSON。完整原始证据留在本机 prototype-sdd/specs/admin-live-reference-2026-09-18/full-content/，需要进一步核查时按其采样范围读取；公开交付不包含原始业务记录。
