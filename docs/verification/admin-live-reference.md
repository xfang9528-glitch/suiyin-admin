# 管理后台对照验收摘要

整理时间：2026-09-20。合同：051@1.1.0、052@1.1.1、053/054/055/056@1.0.0。此摘要记录本轮结构和操作验证；远端发布回执另行记录，不将本机测试时间当部署时间，也不上传客户聊天、原始凭据或浏览器原始捕获。

## 范围与来源

当前为 **15 租户、752 个租户页面入口、84 种路由**。全入口运行来源分布如下：

| 来源状态 | 入口数 | 含义 |
|---|---:|---|
| captured | 183 | 本租户采样，保留采集日期和实际状态 |
| reference | 321 | 明确标注来源租户的参考样本 |
| mock | 237 | 合成演示，不代表真实业务记录 |
| not-captured | 11 | 销售使用统计没有本租户采集，禁止其他租户回退 |

保存的原始内容采集覆盖 283/752 个入口，其中 29 处停留在加载中、73 处为明确空态；469 个入口没有同租户原始内容采集。原始捕获覆盖与当前运行来源是不同口径，不能直接相减当作修复数量。61 种路由有共享几何 profile，不能据此称所有相关租户都采过内容。

销售使用统计单独采用 4 份本租户采集：深圳 94 人、7679 消息、1939 好友；锦帛 4 人、94 消息、41 好友；佰智德三 1 人、12 消息、1 好友；萌爪确认空态。其他 11 租户明确未采集。销售变声统计全部为合成事件，首次成功计次规则与租户隔离可验证，不能称真实使用量。

## 已修正的主要偏差

筛选不再把单选值当日期或用表记录覆盖来源日期；保留原标签、顺序、搜索和重置。实体选项限定当前租户与页面，清除已确认的弹层污染项。表格恢复来源列宽、对齐和空白，分页、刷新、列设置及汇总卡不再无条件出现。

回访搜索按用户截图使用蓝色，账号管理保留直接采样的青绿。使用统计恢复分组、人数和合计；变声统计保留直接日期区间及首次成功计数。菜单新增项与管理库存、平台定义同次登记，原树表和本地权限边界保留。

聊天、配置、预约、好友和销售统计改为按各自来源结构；销售仪表盘恢复 12 指标、4 排行及图表区域。缺明细、缺日期快照和缺展开状态明确提示，不用猜测结果填补。
