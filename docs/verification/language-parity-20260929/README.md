# 话术管理页对齐验证 · 2026-09-29

本目录记录本轮静态 HTML 原型的公开验收摘要。验证覆盖逐租户分类树、话术采样、默认空态、本地编辑与持久化、单文件运行和已采样页面的主要几何位置。它不代表生产后台修改、全量业务数据复制或整页每个像素均无差异。

## 数据与公开边界

公开 Mock 含 **15 个租户、1,246 个分类节点、42 个已采列表分类、155 条列表记录、48 条已采详情、97 段文本和16个图片占位**。其余1,204个分类保留未采样状态；未采列表、内容明细、展示范围及候选选项不会被当作已知空值，也不借用其他租户内容。北京两个同名根节点使用不同稳定标识保留。

本轮没有下载原始媒体。公开产物不包含真实采集文件、整页 DOM、来源数据库标识、私有媒体地址或带查询参数的来源 URL。联系电话、邮箱、凭据和个人信息按公开样本策略过滤；租户名称、分类标题及业务模板用语作为原型内容保留。

[公开数据审计](public-data-audit.json)记录文件摘要、数量、检查边界与重复清洗结果。独立检查在隔离副本上连续执行两次 `sanitize-public-data.mjs`，结构化话术 JSON 的字节摘要保持不变，再次审计通过。旧页面文本的八个通用分类模板不会覆盖新的独立 JSON。

## 可重复验证与限制

公开数据只读审计可运行：

```sh
node prototype/sanitize-public-data.mjs --check
```

启动本仓静态预览后，打开 [常规单文件验收页](../../../prototype/_inline-check.html)执行内置检查。目录版入口为 [_shell.html](../../../prototype/_shell.html)，可离线打开的单文件入口为 [_shell_inline.html](../../../prototype/_shell_inline.html)。报告中的 SHA-256 绑定本次验证的语言 JSON 和单文件构建。

几何结果限定于已记录的视口、控件和状态；字体栅格化及原生滚动条在不同浏览器中可能产生亚像素差异。未采样的分类内容和未覆盖的弹窗状态不属于本轮逐像素一致性结论。字段模式检查与人工审阅互补，不宣称能识别所有可能的敏感值。原始采集截图和私有运行记录未复制到本公开目录。
