## 本轮构建修正及原因

1. `build_admin_inline.mjs` 将 `.page-frame:is([src*=...])` 以及入口中已有的内联 style 一并改写为 `data-inline-src` 选择器，使单文件保留本轮壳字距、行高和提示条样式。此前只处理外链 CSS 中紧邻 `.page-frame` 的 src 属性。
2. 构建 bootstrap 对 `file:` 来源统一为 `null`。实际 Chrome 中父文档 `location.origin` 为 `file://`，srcdoc 为 `null`，消息来源也为 `null`；原先给 `file://` 发消息会丢失，导致抽屉展开后父壳未进入遮罩状态。现在 file 模式使用可接收的目标来源，HTTP 仍使用原同源值。
3. 增加未内嵌脚本/样式及缺失文档标记的构建拒绝检查，构建输出记录脚本、样式数量与 SHA-256。
4. `_inline-check.html` 保留旧检查并追加本轮范围；QA 只清理 `admin-qa` 前缀。费用校验等待初始加载结束，菜单撤销检查真实顺序和业务字段，避免将派生序号规范化误判为用户数据变更。

以上修改仅涉及构建适配和验收文件，没有修改通用产品行为。
