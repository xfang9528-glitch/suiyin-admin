# 真实后台新增页面静态对齐

> **本轮已批准的具体范围：**
> - 15个已登录租户补齐“录音管理”；深圳、嘉兴、杭州、广州、成都补齐“喜报设置/记录”。
> - 录音页复现筛选、七列表格、分页及详情抽屉，含上传信息、分段转写和AI分析页签；无音频文件时明确提示，不假装播放成功。
> - 喜报设置分医生/非医生两区，分别演示图片、顶部距离和颜色；保存仅在当前浏览器生效。
> - 喜报记录复现筛选、九列表格、新增医生/非医生表单和只读详情；取消不保存，本地保存只增加演示行。
> - 菜单顺序及租户差异以本轮实采为准；保留已做的菜单拖动、表头冻结和AI费用等已批准功能。
> - 真实上传、分析、发送及在线保存不接入；未采编辑面板和完整枚举明确延期。瑞熙小周已补实采录音空态。
> - **已批准：房总本轮回复“通过，按此实施”。按以上范围做三个新页静态原型；既有页面对齐继续。**

本文将本轮已批准的轻量合同规范化为同版本远端交付合同；未改变 R-ID、AC-ID 或已批准行为。2026-09-27 房总随后明确“完整推送”，只增加静态发布及文档归档授权。三页默认结构和主要只读面板已足够作具体范围审核；房总已在本轮对引用本文的范围审核问题回复“通过，按此实施”；该批准授权本地静态实施，不构成实施完成或生产能力声明。真实后台持续只读采集和既有页面的已批准纠偏可以继续。

## 1. 审核摘要

- **用户问题**：真实后台菜单和页面已经增加，原型仍停在旧入口和旧界面，无法直接对照评审。
- **完成后变化**：在确实具备入口的租户中，能从原型进入录音管理、喜报设置、喜报记录，并对照当前页面的字段、布局和已采集状态。
- **本次范围**：新增三条 route 的静态复制、正确租户菜单接入、脱敏本地样本及明确列出的本地演示动作；已有页面继续 054/055，菜单状态继续 068。
- **明确不做**：真实录音读取/播放/下载、真实喜报生成/发送、真实设置保存、真实权限修改、生产仓修改和发布。没有采到的状态、按钮结果不猜做。
- **需要房总拍板**：无新增决定。§3/§6 已由房总“通过，按此实施”批准；本次完整推送不增加未采编辑面板、真实媒体或其他服务能力。
- **AI 新提案**：R004–R006 中的本地演示边界已在本轮审核通过；实际生产行为以本轮界面证据为准。

## 2. 用户问题与预期结果

评审者切换同一租户、打开同一菜单时，需要原型与真实环境保持一致；新增菜单缺失、错放或租户混用会使评审落在错误页面。O001：本轮 verified-menu 的新增入口可逐项对照；O002：有实采页面的字段、状态与截图可追溯；O003：本地演示不会被误认为操作了真实环境。

具体可审核面板：

1. **录音详情**：右侧抽屉和关闭入口；文件名、录音类型/时长、上传人、关联客户、上传时间；媒体控制条；“转写文字”“AI分析”页签、“刷新结果”按钮、“已完成”状态。转写按说话人、时间、文字分段；AI分析仅复现已见“客户意图、情感分析、关键词、沟通摘要、客户洞察、跟进建议”结构并填合成样本，不复制真实对话或推定其他分析类型。默认不提供音频，时间标签不伪造回听效果；刷新只重读已存本地结果，不触发分析任务。
2. **喜报设置**：医生喜报、非医生喜报分别维护同样四项；截图提示 JPG/PNG、最大2MB、可更换或清除、不限制图片尺寸，色值支持 #RRGGBB 或 #AARRGGBB、留空白色。本地交互据这些可见约束校验并预览用户自己选的图片；空素材与已有素材使用来源对应“选择图片”/“选择替换图片”。保存仅写当前租户本地样本，刷新重读本地已保存值；不承诺在线素材上传或图片生成。
3. **新增喜报**：喜报类型（医生/非医生）、成交项目、成交时间、派单平台、成交金额（元）、客户电话、派单时间；医生类型额外显示对应医生。已见类型必选标记，金额提示“选填，最多两位小数”；其余不得凭字段名新增必填/手机号格式约束。取消/关闭不写入；本地保存追加当前租户演示行。非医生详情已见类型、项目、成交时间、派单平台、金额、客户电话、派单时间，空派单时间显示“—”；详情只读。未采编辑面板先不泛化复用新增表单。

## 5. 用户场景与验收

### US01 — 从当前租户进入新增页面

#### AC-R001-01 — 租户入口正确
- Given 本轮证据确认租户菜单存在该 route。
- When 打开本地 Shell 和新增入口。
- Then 导航父级/顺序/标签/图标与该租户证据匹配，页面不借其他租户内容；未采租户明确保留缺口。

#### AC-R002-01 — 旧菜单调整保留
- Given 本地保存过租户排序、跨组归属或隐藏设置。
- When 加载新快照与新增入口。
- Then 保留显式设置；新成员按068规则追加；平台限制与租户权限仍生效；已有AI费用等不被删除。

### US02 — 对照三个新增页面

#### AC-R003-01 — 默认页与来源对应
- Given 相同租户、route、视口和DPR的本轮截图。
- When 对照本地新页。
- Then §3字段、顺序、已见按钮、分页及几何与证据一致；脱敏内容不冒充实时业务数据；表头继承冻结。

#### AC-R004-01 — 已见查询与本地状态
- Given 使用当前租户的本地样本。
- When 查询、重置、分页或打开已采详情。
- Then 仅作用该本地样本；已提交筛选与草稿、空结果、取消/返回状态按已采交互明确实现，不调用真实服务。

#### AC-R005-01 — 写入型按钮的静态边界
- Given 原站存在保存/新增/编辑/替换图片按钮且对应表单证据已补齐。
- When 在原型内确认该动作。
- Then 仅保存本浏览器该租户的演示数据，明确本地结果；刷新/恢复按审核通过的本地契约执行，无真实上传、保存、生成或发送。

#### AC-R006-01 — 缺证据状态不伪造
- Given 操作的面板、校验或结果尚未采到，或不存在可用本地媒体。
- When 尝试该动作。
- Then 保留明确待补状态；不复用万能编辑表单、不显示已处理/已播放/已发送等成功反馈，不请求真实媒体。

#### AC-R007-01 — 像素验收有证据
- Given 完成的静态页面与当前来源截图。
- When 同视口逐项比较并滚动。
- Then 筛选/表头/行/分页/浮层对应几何有对照记录；仅DOM检查通过时仍标视觉待验证，不宣称所有租户逐像素一致。

#### AC-R008-01 — 喜报设置按类型分别演示
- Given 当前租户的医生/非医生设置区域及本地素材。
- When 修改一类的图片/顶部距离/颜色，取消选图或保存后刷新。
- Then 两类值不串用；取消选图不变；图片及颜色按已见提示校验，本地保存后恢复该租户本地值；真实空素材保持空，不补深圳图片。

#### AC-R009-01 — 新增喜报切换类型
- Given 打开当前租户新增喜报的本地草稿。
- When 在医生/非医生类型间切换、取消或保存本地样本。
- Then 对应医生只在医生类型出现；非医生结果不显示陈旧医生值；取消不追加行，保存只追加本地演示行；遵守类型必选及金额最多两位小数的可见约束，未验证其他校验不扩加。

#### AC-R010-01 — 录音详情和结果切换
- Given 打开本地脱敏录音详情。
- When 切换转写文字/AI分析、关闭抽屉、点击刷新或没有本地音频的时间/播放入口。
- Then 元数据及分段/分类结构来自已见界面，关闭返回列表且保留筛选；刷新只读本地结果；没有音频时说明未提供文件，不播放真实媒体、不虚报生成分析。
