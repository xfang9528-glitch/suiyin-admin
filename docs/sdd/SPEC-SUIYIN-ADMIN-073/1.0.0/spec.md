# 工具管理与艺星辅助线自助管理

## 1. 审核摘要

- **用户问题**：艺星客户要增加、替换或移除 PC 图片编辑中的医美辅助线，目前要找工程师改素材并等待发版，无法自己维护。
- **完成后变化**：客户在「工具管理 → 辅助线管理」管理自己租户的分类和图片；现有默认、门店专属素材都成为本租户可编辑的初始配置，其他租户不受影响。
- **本次范围**：所有租户把原一级「话术管理」在原位置改为「工具管理」，原话术页面保留为其二级「话术管理」；所有艺星租户再增加二级「辅助线管理」。提供分类和图片增删改、排序、启停、上传状态及 PC 效果预览。
- **明确不做**：本轮交付静态 Admin 原型，不实现生产接口、真实素材上传、客户端同步或改动生产仓；PC 工具内部线条不拆分编辑。
- **已确认**：Q001 已采纳——现有全部内容可由本租户增删改，初始按各租户当前可见内容保留，不扩散到其他租户。
- **需要房总拍板**：无；房总在具体方案确认问题后回复“执行”，批准每个后台租户一套配置及本方案。
- **AI 新提案**：本轮按租户一套配置；页面草稿统一保存、未保存离开提示；透明 PNG 上传示例上限 10MiB；后台显示可编辑管理名称，PC 预览继续只显示分类和缩略图。对应 R004–R009，房总于2026-09-29回复“执行”，已采纳。

## 2. 用户问题与预期结果

### 2.1 用户与场景

艺星企业运营在后台维护咨询师日常使用的医美辅助线。PC 咨询师在现有图片编辑或截图编辑里按分类选择辅助图，插入后继续拖动、缩放、旋转和删除对象。

### 2.2 用户问题

现有默认素材和部分门店独立素材依赖工程师维护，客户不能及时调整本店需要的分类与图片，门店差异容易累积成多套硬编码配置。

### 2.3 完成后用户能感受到的变化

客户可以自己加分类、传辅助线、替换图片、改名称、调顺序或删除不需要的内容；本租户已有内容全部可管理。业务目标是保存后供本租户 PC 使用；静态原型仅验证管理与预览流程，不宣称已与真实 PC 联通。

### 2.4 成功信号

| ID | 可观察信号 | 判定方式 |
|---|---|---|
| O001 | 全部租户的话术入口位于工具管理内，原话术数据和编辑能力保留 | 15 个现有租户菜单回归 |
| O002 | 艺星客户可维护本租户既有与新增辅助线，非艺星无业务入口和数据 | 6 个现有艺星及 9 个非艺星隔离检查 |
| O003 | 保存后的顺序、启停和素材内容与 PC 效果预览一致 | CRUD、保存、刷新、预览操作 |

## 3. 范围

### 3.1 In Scope

- 一级「工具管理」及二级「话术管理」「辅助线管理」的导航、普通菜单管理和平台菜单定义联动。
- 现有话术路由、状态键、分类与话术内容保持兼容；只调整其默认导航层级。
- 辅助线分类：新增、改名、删除、排序、启用和停用。
- 分类下图片：批量选择、添加、管理名称修改、替换、删除、排序和预览。
- 各租户现有默认及专属素材初始化、本租户编辑隔离、保存与失败恢复。
- Admin 内嵌 PC 效果预览；沿用原 PC 分类与纯缩略图选择方式。

### 3.2 Out of Scope

- 同一租户内按门店或人设细分；Q002已明确每个后台租户一套。
- 真实数据库迁移、上传服务、接口契约、PC 配置刷新时效和生产权限实现。
- 新增 PC 基础绘图能力、修改 PNG 内部医学标注、APP 消费端。
- 全局素材市场、跨租户复制、批量向艺星所有店发布或恢复默认按钮。
- Flutter / React / Go 等生产端实现不在本规格范围。

### 4.1 已发现冲突

- Issue #2 / #7584 的旧「跨租户通用」范围与 E001 不同：本次辅助线仅艺星，工具父级和话术仍全部租户；没有自行改写工程单。
- Issue 中默认叠加/覆盖和存量迁移原未明确，由 E004 收准：按当前租户原可见内容初始化，全部允许该租户增删改；来源标签只说明来源，不构成只读限制。不把其他店素材合并到本店。
- 030 排除了后台素材管理和自定义上传，属于当时 PC 实现范围。本新规格承接 Admin 管理范围，批准后只补充配置管理与预览合同；030 的 PC 操作语义继续有效。
- 030的R004“全部来自原PPT”及R015的固定123文件/129条、两仓同目录，是旧固定素材库合同。073仅继承其PC展示、透明叠加和对象操作语义；16/129/123是本地初始样本，不约束用户增删改后的有效配置，也不要求各租户编辑后仍相同。旧030快照保持不变。
- 030 的旧五城样例和本地 PC 注册表不含北京，不能缩小 E001 的「所有艺星」。Admin 当前验收为六艺星，未来以真实艺星身份继承。
- 现有一级 `languageManage` 调整为工具管理下的二级同一路由。菜单表、平台定义、页签恢复和旧链接一起兼容，不能只改侧栏文字。

## 5. 用户场景与验收

### US01 — 所有租户从工具管理进入原有话术页

#### AC-R001-01 — 父子菜单一致
- Given 当前任意租户保留现有菜单与话术数据。
- When 打开导航、普通菜单管理或平台定义。
- Then 工具管理替换原一级话术的位置，默认结构为工具管理 → 话术管理；艺星另有辅助线管理，平台登记唯一对应定义，不出现重复话术入口，也不统一追加到菜单末尾。

#### AC-R002-01 — 话术链接与状态兼容
- Given 用户保存过话术编辑、分类或菜单调整，并有旧话术直达链接。
- When 更新导航后打开或刷新该链接。
- Then 仍打开本租户话术页，业务数据不重置；旧话术的独立隐藏、权限继续约束其二级入口，新增父级不让隐藏话术复活。工具父级按其可见子项显示；其他菜单的合法自定义顺序和归属保留，仅本次入口迁到指定新层级。

### US02 — 艺星运营维护自己租户的辅助线

#### AC-R003-01 — 艺星范围与租户隔离
- Given 六个现有艺星和九个非艺星样例。
- When 通过菜单或直接链接打开辅助线管理，或 A 租户编辑中切到 B。
- Then 艺星读写各自配置；非艺星无入口且不给业务数据；切换不会把 A 的素材、草稿或异步结果落到 B。

#### AC-R004-01 — 既有内容可管理且完整保留
- Given 某艺星租户当前有默认素材和本店独立包。
- When 第一次初始化并分别编辑默认、本店来源的分类和图片。
- Then 初始内容与该租户原可见清单一致，不丢、不重复、不混入其他店；两种来源均可由本租户修改，其他租户保持原状。未取得该店来源时明确为演示样例，不伪称完成生产迁移。

#### AC-R005-01 — 分类完整操作
- Given 当前租户有分类及图片。
- When 新增、改名、排序、启停，或删除含图片的分类并确认/取消。
- Then 空名称不能保存，同租户重复分类名有明确校验；排序和启停在预览一致；删除前说明受影响图片数，取消不改变草稿。全部删除后显示已配置为空，不自动恢复默认素材。

#### AC-R006-01 — 图片完整操作
- Given 当前分类有现有图片。
- When 批量添加、改管理名称、替换、排序、移除或取消替换。
- Then 原条目身份和顺序在替换成功前保持，取消/失败仍保留原图；同一操作重复触发不产生重复条目；同图在不同分类的合法入口仍分别保留，替换只改变当前条目，不改变其他分类或租户的引用；删除仅移除当前条目，不按共享文件名连带删除。共享初始文件不改写，已输出图片不被追改。

### US03 — 上传、保存和预览有明确结果

#### AC-R007-01 — 上传失败与竞态
- Given 同批合法 PNG、格式不支持、超过原型示例限制及模拟上传失败文件。
- When 批量选择，重试失败项，或处理中移除该项/切租户。
- Then 逐项显示结果与可读原因、重试/重新选择入口；未成功项不能作为有效素材保存，已移除或旧租户的迟到结果不复活、不重复；模拟失败可查看示例取证信息。

#### AC-R008-01 — 保存、取消与恢复
- Given 当前租户有未保存草稿，或本地保存失败。
- When 保存、重复保存、在应用内关闭业务页签或切租户，或通过浏览器刷新/关闭。
- Then 提交中禁用重复提交；成功后本地已保存版本与预览一致；失败保留草稿和原已存版本。应用内离开提供保存/放弃/继续编辑；浏览器刷新或关闭仅使用浏览器允许的原生离开提示，不能承诺自定义三按钮。确认离开后未保存草稿丢弃，重开恢复已保存版本；未保存变更不冒充已生效。

#### AC-R009-01 — PC 效果预览符合既有用法
- Given 当前租户配置存在启用及停用分类，部分草稿尚未保存。
- When 打开 PC 效果预览、切分类、选择透明辅助图并拖动、缩放、旋转、删除。
- Then 只展示该租户启用内容及相同顺序；只显示业务分类名与工具缩略图，管理名称和来源页不挤入 PC 卡片；草稿预览明确未保存，预览动作不更改配置。

#### AC-R010-01 — 窗口、空态和异常可操作
- Given 1280×720 窗口，或无分类、无图片、素材加载失败的场景。
- When 操作分类区、图片网格、上传/编辑弹窗及预览。
- Then 关键操作始终可见，无页面横向滚动条，长内容在所属区域纵向滚动；确认空态、加载中与错误明确区分，键盘焦点和关闭返回可用。

#### AC-R011-01 — 原型能力如实表达
- Given 用户在本原型完成增删改并保存。
- When 查看保存反馈与预览。
- Then 反馈为本地原型保存，不能显示真实 PC 同步成功、真实上传成功或生产迁移完成；页面只使用本地资源或明确媒体占位。

### 7.3 进入、退出与恢复

工具管理展开后进入对应子页；话术旧链接继续有效。辅助线首次进入加载本租户已存数据，未配置时初始化来源；未知来源用明确演示数据。取消单项编辑回到原草稿；应用内离开与浏览器离开分别按R008处理；刷新重开只恢复已保存版本，不自动保存或恢复已放弃的草稿。错误反馈保留重试出路，异步操作绑定租户和条目身份。
