# AI费用统计

## 1. 审核摘要

- **用户问题**：只有三天样本，不便给客户展示长期使用趋势；每项分析由什么专属模型提供也不直观。
- **完成后变化**：可查看跨三个月的演示用量和费用，在各分析项目旁看到对应模型品牌名与用途，强化碎银专属模型的辨识度。
- **本次范围**：在1.1.0基础上将样本扩为2026-07-01至2026-09-20共82天；表格新增专属模型列，单类图表提示同步模型名；保持既有查询、计次、费用和13租户范围。
- **明确不做**：真实账单、实际历史模型调用核验、调价、模型配置编辑、模型筛选、模型版本编造、额外项目扩容。静态原型完整推送及工程建单现已由E020授权。
- **需要房总拍板**：无新增阻塞；Q006已由房总“按照这个做”明确采纳；Q002–Q004继续演示/待确认。
- **AI 新提案**：R016–R019：完整日期覆盖及稳定波动样本、专属模型列、模型信息与趋势联动、品牌名称与实际调用证据分开。这些增量已由E019批准；R001–R015保持已批准行为，固定样本日期与旧三列表格按本次变更替换。

## 2. 用户问题与预期结果

### 2.1 用户与场景

- 用户角色：当前租户具有 AI 管理查看权限的客户管理员。
- 触发场景：查看某一天或一段日期内，AI 做了哪些分析、用了多少次、费用分别是多少。
- 当前做法：分散查看客户标签、客户画像、AI辅助等统计；发送构成、Token消耗和客户费用不是同一指标。

### 2.2 用户问题

功能页面的“使用次数”可能表示发送、客户数、业务任务或模型请求；直接乘统一单价会造成误解。自动任务、按需调用以及尚未核算金额也容易被混为一谈。

### 2.3 完成后用户能感受到的变化

选择日期后，可以读懂每类 AI 分析做了多少次、对应多少费用；部分金额未确认时知道总费用尚不完整，不会把缺数据理解为免费。

### 2.4 成功信号

| ID | 可观察信号 | 判定方式 |
|---|---|---|
| O001 | 从 AI管理直接打开本租户统计页 | 原型点击及租户切换 |
| O002 | 单日/范围的次数与费用汇总能由同一演示记录复算 | 固定记录人工复算 |
| O003 | 未核算、未启用、零使用和读取失败有不同表达 | 边界状态验证 |

## 3. 范围

### 3.1 In Scope

- 「AI管理」增加「AI费用统计」二级目录，并保持同租户菜单管理/已有平台菜单定义与实际入口一致。
- 筛选只提供时间：单日、范围、今天/昨天/前天、搜索、重置。“范围”解释为日期范围，不主动扩展部门、员工、账号、模型等维度。
- 核心表格由三列扩为「分析项目、专属模型、分析次数、费用（元）」；表尾合计。项目状态与金额状态直接写在相应单元格或说明中，不额外堆指标卡；本轮新增折线趋势图，取代旧版不做走势图的范围约束。
- 初版建议五类：客户标签、客户画像、沟通进度分析、AI辅助回复，以及盘点新增的AI上下文整理。其余朋友圈评论、客服能力分析、线下沟通分析、转写纠错先记录在盘点清单；确认费用归属后再决定独立列项或归入现有项目。不能把模型配置目录直接当作每日执行或收费清单。
- 趋势图置于统计表上方，包含“分析次数/费用”切换和“全部已列项目/五类之一”类别选择；一次展示一条对应折线。类别仅过滤图表，下方表格始终保留五类明细。
- 演示日期扩展为2026-07-01至2026-09-20，共82个上海自然日；数据按租户隔离、按天连续覆盖，仍可呈现零使用与费用待确认。

- 静态演示状态：正常、全零、部分费用待确认、未启用、缺日期样本、加载失败及重试、无权限，以及趋势断线/部分空心点/单点。

### 4.1 已发现冲突

- 现有AI辅助统计的AI直发/AI参考/手动文本是发送构成，不是业务分析任务数或付费请求数。保留旧页定义，新增费用页独立取数，禁止套用旧页数据换算。
- 平台已有供应商采购成本记录，不等于客户实际扣费。两种金额不得混合求和；本次客户页面采用哪种账务依据由Q003确认。
- 每日定时和用户按需触发都能产生当日费用，不能把所有项目宣称为“每日自动分析”。实际运行清单见inventory.md的证据等级。
- 现有页面以历史采集为依据；本页是新增设计，无真实原站页面可照抄。新增统计数据均明确标识为合成演示，不能借旧快照冒充当前账单。
- 15个登记租户不等于15个都有AI管理；本次只在现有13个父级下追加。父id按租户不同为group-10/group-11/group-12，不能硬编码一个全局父id；未配置父级的两个租户暂不扩展。

## 5. 用户场景与验收

### US01 — 找到费用并切换日期

#### AC-R001-01 — 二级入口与菜单一致
- Given 当前租户有AI管理查看权限。
- When 展开AI管理并打开AI费用统计，再查看菜单配置。
- Then 页面和菜单项使用同一稳定身份；父级、名称和可见状态一致；隐藏或无权限时直链不能绕过。

#### AC-R002-01 — 单日与范围
- Given 默认上海今天，固定演示时间为2026-09-20。
- When 输入单日或完整日期范围并点击搜索。
- Then 只统计所选本地自然日；日期草稿未提交时旧结果与旧已应用日期保持一致；范围含首尾日。

#### AC-R002-02 — 日期边界与恢复
- Given 日期缺失、非法或起日在结束日之后。
- When 搜索、取消日历或重置。
- Then 非法值不提交且说明原因；Escape取消未完成选择并返焦点；重置回今天单日并查询；快捷日立即查询，保留当前单日/范围模式。

### US02 — 看清哪些分析产生了费用

#### AC-R003-01 — 项目清单不冒充日调度
- Given 四个用户点名项目、已查证调度定义的AI上下文整理及待确认额外项目。
- When 查看统计与口径说明。
- Then 五类核心项目可辨认；合并分类不重复计数；每日扫描说明不冒充今日执行记录，未经确认的额外项目不伪称已开通/每天执行；未启用与零使用区分。

#### AC-R004-01 — 次数与请求分开
- Given 一个业务分析发生两次模型请求，第二次为自动重试；另有一项成功业务分析。
- When 按提案口径查看分析次数。
- Then 首次成功的独立业务分析共计2次，自动重试不新增业务分析次数；不能用模型请求条数或AI消息发送条数替代。若真实业务ID无法提供，次数显示待确认，不假造去重。

#### AC-R004-02 — 失败及跨日不强行一一对应
- Given 一个失败业务没有成功完成但有已确认客户费用，另一个任务跨日首次成功。
- When 按本页提案查询各日。
- Then 失败业务不新增成功分析次数，但保留费用记录对应日期的金额；跨日任务只在首次成功完成日计1次，已发生费用不搬日；解释次数和费用并非固定单价的一一对应关系。

#### AC-R005-01 — 客户金额与内部成本分开
- Given 同一分析有供应商成本记录，但没有已确认客户扣费记录。
- When 展示客户费用。
- Then 客户费用显示待确认；不得把供应商成本当实际扣费、乘自定倍率或把缺单价写0。

#### AC-R005-02 — 真实零和很小的金额
- Given 已确认0费用和已确认正数但小于0.01元两类记录。
- When 展示金额。
- Then 分别显示0.00和小于0.01；舍入不把正消耗伪装为零。失败/重试的真实客户费用由已确认收费记录决定，不由前端成功次数推算。

#### AC-R006-01 — 合计完整与不完整
- Given 各项目已知金额为1.23、0.50、0.00，第四项待确认。
- When 查看表尾合计。
- Then 显示“已确认费用1.73元，1项待确认”，不能显示“总费用1.73元”；无任何已知金额时只显示费用待确认。次数口径完整时单独正常合计。

#### AC-R006-02 — 项目和归类覆盖不完整
- Given 表内五类金额均已知，但其他候选场景尚未核实是否有费用，或存在有金额的未归类记录。
- When 查看合计。
- Then 只标“已列项目费用”，附“项目覆盖待确认/有费用待归类”；未归类已知金额单独说明为“未归类费用”，不得消失或重复并入五类；不称全部AI总费用。只有项目、归类、金额与日期均完整时才允许完整总计。

#### AC-R006-03 — 范围部分日期缺失
- Given 样本覆盖7月1日至9月20日，查询6月30日至9月20日。
- When 搜索范围。
- Then 保留有样本日期可复算的结果，明确“已覆盖7月1日至9月20日，6月30日缺少样本”；分析次数与费用合计都标已覆盖部分，不按缺失日0次/0元计算，不称完整范围总计。

### US03 — 安全查看本租户与异常结果

#### AC-R007-01 — 租户与权限隔离
- Given 两个租户各有不同演示记录，其中一个菜单隐藏。
- When 切换租户或尝试直接路由。
- Then 不沿用上一租户数据/合计；隐藏页被拦截；不得以本地隐藏验证了生产鉴权。

#### AC-R008-01 — 演示与未知表达
- Given 固定演示日期及其记录，另有缺样本日期、真实零样本和费用未确认样本。
- When 切换日期查看。
- Then 演示标识始终可见；缺样本不写0；真实零与未核算分开；不将示例金额表示为正式报价。

#### AC-R009-01 — 加载错误和交互状态
- Given 读取失败或正在加载。

- INV009：完整实线仅连接相邻自然日的完整点；缺样本、未启用、全部未知和部分已知均打断实线；空心部分点不被当作完整总量。

- INV010：专属模型名称是本次演示项目映射，不等于历史实际调用证据；一个模型服务多个项目时不增加分析或费用。
