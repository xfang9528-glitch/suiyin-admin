# AI费用统计：趋势图变更审核

版本：SPEC-SUIYIN-ADMIN-058@1.1.0 / approved。原1.0.0页面已实现，当前保持可用。

用户新增要求：“还需要一个折线图能看到使用趋势，也能分类别看”。

建议本轮这样补：

1. **位置与指标**：表格上方放一张「使用趋势」折线图；默认分析次数，可切换费用（元）。
2. **类别**：选择全部已列项目，或客户标签、客户画像、AI上下文、沟通进度、AI辅助中的一种；一次展示一条对应趋势线。类别只改变图表，下方表格保留全部类别明细，方便核对。
3. **日期**：跟随现有单日／范围搜索结果，横轴按天。单日一个点，提示切到范围查看多日趋势；不擅自增加小时维度或改变默认今天。
4. **点值**：鼠标悬停或键盘聚焦显示日期、类别、次数或金额。未知日期断线，已知零画零；部分已知用不连线的空心点并注明已确认部分，避免当作完整费用。
5. **一致性**：每日值仍取同一批演示事件和费用记录；全部趋势能与表尾的已列项目合计复算，单类趋势能与对应行复算。已知部分按完整精度相加。

这次只增加本地静态图表交互，不改变计费规则、租户覆盖和发布状态。费用继续明确为演示／待确认。
