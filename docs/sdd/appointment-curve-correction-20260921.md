# 预约累计曲线连续显示 — 视觉修复

日期：2026-09-21；发布标签：v2026092102-admin-appointment-curve。

用户反馈“总数曲线不应该有断点，0的日期，应该是在同样的高度有圆圈，且虚线能连上”，本地修复后用户确认“修复好了，完整推送”。本次为L0绘图表达修复，继续执行[062@1.0.0行为合同](SPEC-SUIYIN-ADMIN-062/1.0.0/spec.md)，不改变预约计数、筛选、来源或租户范围。

## 当前展示

- 累计曲线逐日保留空心圆点，统一以青绿虚线连续连接，图例同步。
- 当天预约量为0，累计值沿用前一天，因此相邻圆点同高。例：演示数据9月6日当天0条、累计38条。
- 样本模式的空日期保留“每日预约量：未采到明细”，不生成真实0柱形；已采样累计值逐日延续，不能视为真实全量。
- 总量、列表、两组日期筛选、缺预约时间、单日、空态和权限继续按原合同。
