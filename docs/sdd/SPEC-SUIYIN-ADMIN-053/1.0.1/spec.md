# 销售使用统计真实结构与租户隔离纠偏

## 1. 审核摘要

- **用户问题**：销售使用统计的通用列表掩盖销售与部门分组，日期查询失效，部门选项跨租户串用，无法作为真实后台的原型参照。
- **完成后变化**：恢复统计标题、人数与合计、销售分组和正确筛选；无多余卡片/分页；各租户只展示自己的已采集证据。
- **本次范围**：salesMessageUsage 的十五租户数据模型、专用页面、筛选/排序/导出及直接预览。
- **明确不做**：不写线上、不进生产仓；静态原型发布按本轮“完整推送”授权；不将旧快照或静态模拟当成当前线上数据/逐像素证据。
- **需要房总拍板**：无。房总在完整差异清单后明确“全部对齐哈”，构成本次纠偏授权。
- **AI 新提案**：无新增业务。快照可用性、分组模型、导出明细和日历是静态实现选择，详见默认值与证据边界。

## 2. 用户问题与预期结果

### 2.1 用户与场景
房总对照真实销售使用统计，评审新统计页面和租户效果。
### 2.2 用户问题
当前原型会把有数据日期筛空、将全表合计当销售排序、显示外租户部门；仅调共享CSS不能恢复真实统计结构。
### 2.3 完成后用户能感受到的变化
同一销售的部门与小计连续可读，人数与合计一致；日期有效，空数据与缺少快照分清；不再出现外租户样本冒充当前数据。

## 5. 用户场景与验收
### US01 — 查看本租户统计
#### AC-R001-01 — 标题与表结构
- Given 已采集深圳数据。
- When 打开统计页。
- Then 展示业务标题和使用人数/消息/好友合计；同销售部门、小计连续，tfoot全表合计无销售名；无额外指标卡/分页/工具栏。
#### AC-R002-01 — 日期与查询
- Given 初始样本日期。
- When 选择同日、有效范围、快捷今天及重置。
- Then 草稿不提前刷新；仅有完整日期样本时汇总；含未采集日期的区间明确缺少快照；今天使用上海当前日期；无该日样本明确提示，不宣称业务零值；逆序/缺失不提交。
#### AC-R003-01 — 租户隔离
- Given 四份本租户采集及十一份缺证据页面。
- When 切换租户、展开部门。
- Then 仅当前租户采样部门；萌爪为采集空态，其余未采集不出现深圳人员/数量。
#### AC-R004-01 — 分组排序
- Given 多部门销售和小计。
- When 按消息或好友升降序排序。
- Then 按销售当前筛选后汇总排序，明细/小计保持一起，tfoot始终最后。
#### AC-R005-01 — 导出
- Given 有筛选结果或空态。
- When 导出。
- Then 只导出当前筛选明细，各数字总和等于页上合计，无小计重复累计；空/缺样本/加载禁用。
#### AC-R006-01 — 控件和样式
- Given 本地页面。
- When 使用日期弹层、部门下拉、键盘和窄窗。
- Then 六列留白真实为空、两个数值列右对齐，搜索/重置/导出同组，无原生日期模式造成缺失；保存实际视觉状态或明确阻塞。
#### AC-R007-01 — 异常状态
- Given 数据读取失败或菜单不可见。
- When 进入页面或重试。
- Then 错误/空态/未采集分别反馈，隐藏菜单直链不能绕过；重试不变更查询。
