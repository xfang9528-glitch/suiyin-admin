# 现有管理后台完整内容与真实界面对照迭代

本文件记录用户直接执行指令及其纠偏，不声称用户另外审阅过生成文件。2026-09-19 仅将已有规则整理为标准合同结构、补齐来源与交付授权，未新增业务范围或扩大生产权限。

## 1. 审核摘要

- **用户问题**：此前原型仅补齐导航，内容数据、按钮展开和页面结构仍有空缺，菜单树被通用表格替代，无法可靠对照真实后台。
- **完成后变化**：进入保留租户能看到完整页面、可操作样本和实际展开控件；菜单管理恢复真实树表与本租户侧栏配置联动。
- **本次范围**：十五租户、737 个租户路由组合、83 种路由；静态内容、Mock、本地状态和真实 UI 对照。
- **明确不做**：不修改线上配置，不接真实认证或写 API，不进入 Flutter / React / Go 生产仓，不把样本当实时全量事实，不创建工程 Issue。
- **需要房总拍板**：无；内容实施、补齐数据与展开界面、视觉纠偏及本次完整推送均已有明确指令。
- **AI 新提案**：无新增；样本回退、组件复用和本地存储为原已授权实现选择，必须保留来源标识与隔离。

## 2. 用户问题与预期结果

房总及原型评审者需要将现有原型与真实管理后台并排核对。空表、通用占位或同一布局不能验证完整流程；同名不同路由、不同租户配置和真实空值也容易被抹平。

完成后可在本地查看内容、展开下拉与弹窗、修改和取消 Mock、刷新读回本地结果。来源标签区分本租户采样、参考样本和合成演示。路由完整性、流程验收与视觉证据分别报告，不用 737 次载入证明像素一致。

## 5. 用户场景与验收

### US01 — 进入完整内容并核对结构

#### AC-R001-01 — 内容入口覆盖
- Given 已批准的十五租户导航。
- When 逐项进入已登记路由。
- Then 每个入口有页面实现和采样状态，不以统一占位替代已采样内容。

#### AC-R005-01 — 领域结构保真
- Given 原站表格、树、配置、聊天或图表页面。
- When 同租户、同视口比较字段、筛选、动作与布局。
- Then 使用对应领域结构；菜单有层级、展开、开关和固定操作，无原站没有的通用搜索/分页栏。

#### AC-R010-01 — 数据与展开完整
- Given 来源可读且页面应有内容。
- When 打开首屏、下拉和按钮展开界面。
- Then 有注明来源的可操作样本、实际选项与对应领域内容；原站有意空字段仍为空。

### US02 — 操作本地 Mock 并识别来源

#### AC-R002-01 — 本地操作边界
- Given 原型表单已打开。
- When 保存、取消、审核、删除或配置 Mock。
- Then 仅写本地状态，保存可读回，取消不改值，危险操作指明对象并确认，不提交真实后台。

#### AC-R003-01 — 归属与隔离
- Given 两租户同一路由及已标识样本。
- When 切换、刷新或保存本地修改。
- Then tenant + route 状态隔离；本租户采样优先，参考/合成样本标明来源，不冒充目标租户线上事实，联系信息脱敏。

#### AC-R004-01 — 边界反馈
- Given 有筛选、分页或表单的页面。
- When 查询无结果、输入非法日期/缺必填、翻页、删除末页记录、取消或 Escape 关闭。
- Then 筛选结果、页码、校验和焦点恢复有实际本地反馈，不只显示成功提示。

#### AC-R006-01 — 样本与全量分开
- Given 表格或图表显示样本。
- When 查看总量、分页、时间和详情。
- Then 本地样本量与线上总量分开，图表有来源/时间，未采明细不编造成真实事实。

#### AC-R007-01 — 统计定义继承
- Given AI 辅助或工作账号触达统计。
- When 汇总或切换维度。
- Then AI 三类来源互斥，占比由汇总分子分母重算；人数与成功消息数分开，不新增效果因果结论。

#### AC-R008-01 — 访问失败
- Given 来源页面不可读。
- When 记录采样与覆盖度。
- Then 记录失败原因并跳过，不写成采集成功或统计为零。

#### AC-R009-01 — 静态运行与交付
- Given 当前原型和 2026-09-19 完整推送授权。
- When 检查运行请求与交付范围。
- Then 只使用 HTML/CSS/JS、静态数据资源和浏览器本地存储，发布只进入当前原型仓，无真实写 API 或生产改动。

## 7. 状态与交互

默认、加载、查询无结果、读取失败、重试分别表达。表单包含 hover、focus-visible、必填与非法值、取消、保存回读、Escape 和关闭后焦点恢复。长表/下拉可滚动，不剔除禁用选项。删除展示对象与确认，普通记录保留已有撤销行为。菜单可展开收起，名称按来源只读，排序允许来源存在的负数，本地菜单设置联动本租户侧栏。

真实控件只打开读取并取消；本地演示不出现线上保存/发送成功承诺。

## 8. 数据、权限与隐私

数据以 tenant + route 定位，本地存储隔离。采样不是全部历史。公开包只包含脱敏原型、必要合同及验收摘要；原始捕获、客户聊天截图、凭据与报告附件留在本机。无法证明的角色权限仅保留采样事实，不推导权限模型。

## 9. 端与租户差异

只适用 Admin 静态原型；PC/APP 和生产应用不改。按各租户菜单、名称、显示、路由及来源覆盖。同名不同路由不合并；隐藏父菜单影响侧栏可见入口，完整菜单库存仍保留。

## 10. 原型实现契约

实现限 suiyin-admin/prototype/：Shell/导航、admin-content、领域/扩展流程、页面编辑器、admin-menu-tree、原站 SVG/样式与静态数据。R/AC 落点见 plan.md、tasks.md。默认 Chrome 预览。

交付含 SPEC/Plan/Tasks/Source Convergence、公开验收摘要及依赖入口。稳定链路为 SPEC-ID@version → R-ID → AC-ID → Issue Slice → Test ID；后两项只有另行明确工程交付才建立，本次未生成新 Handoff/Test Contract 或真实 Issue。

## 11. 非目标与约束
