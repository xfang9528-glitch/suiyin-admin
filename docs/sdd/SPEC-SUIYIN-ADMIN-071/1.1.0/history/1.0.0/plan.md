## 5. 信息结构

- 列表：名称/目的、账号范围、时间条件、选中与排除摘要、每日运行时间、状态、编辑/复制/启停。
- 整页编辑：基本信息、账号范围、选中条件、排除条件、运行设置；右侧或底部规则摘要。
- 21项选中维度和26项排除维度均能添加，选中全部满足、排除任一满足；账号范围作为首个选中维度。
- 名称与回访目的简洁；不强加父级计划，不增加员工部门。
- 主操作保存，次操作取消；顶部固定简短“本地演示”说明，具体时间口径放说明弹层。

## 7. Mock 方案

固定合成账号按自媒体/抖音IP/小红书/电商/代运营分组；名字明确演示。预置3/5/7天规则，独立副本，其中第7天差异只作为演示。固定样本覆盖单向消息、到期/未到期、未知、0命中与账号权限过滤。未决时间按第0天/48小时，成功普通与群发/手机同步合成消息可计，系统/失败不计；不声称这就是上线口径。

## 8. 验证计划

浏览器按关键AC验证新建、全维度选择、群组及单账号多选、复制修改不联动、取消不保存、零命中可保存、启停、刷新持久化、跨租户不出现新页与字段、旧群发/统计入口正常。模型检查AND/OR、相对日期、未知消息与账号权限的真实集合输出。桌面及窄窗检查可滚动、无不可用遮挡。

## 9. 风险与回退

现有仓起始无修改；使用专用rr模块和匹配route的提前分流。其他路由继续原初始化。保存错误不改变原状态，不使用随机结果。恢复仅针对本页命名的本地演示键，不清理其他原型数据。
