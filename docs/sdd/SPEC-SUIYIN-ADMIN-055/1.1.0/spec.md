# 管理列表筛选表格及来源一致性

## 1. 审核摘要
- **用户问题**：销售使用统计暴露了通用实现与实际页面之间的差距，同样偏差也存在于整个管理后台。
- **完成后变化**：有来源的结构和交互按真实页面恢复，各租户来源透明；管理者向下查看长表时表头持续可见，能辨认每列含义。
- **本次范围**：管理列表筛选表格及来源一致性；按源表单保留字段标签、日期初值、单选和复选结构；查询和重置依据真实动作，不普遍添加日期快捷项。 下拉选项以当前租户当前页面上下文为优先，不借用其他租户的实体选项；枚举与实体分开。 表格列的宽度、对齐、可排序属性以对应采样为准，保留空白列；分页及额外工具仅在来源要求时出现。 不向每个统计页自动插入汇总卡；来源说明直接区分本租户采样、参考样本与合成演示。
- **明确不做**：不修改线上和生产仓，不增加冻结列或更改业务字段/数据；本轮已获完整推送授权，发布新版本合同与派生产物；不改旧版本快照。历史采集或 DOM 检查不代表当前线上逐像素一致。
- **需要房总拍板**：无；既有范围来自全管理页一致指令，本次表头冻结由 E005 明确直接确认。
- **AI 新提案**：无新增业务；证据矩阵、专用渲染和来源提示为实现选择。

## 2. 用户问题与预期结果
评审者在相同租户页面对照筛选、表格、操作和内容。此前通用模板添加不存在的功能，削弱真实页面参照价值。
O001：所有登记入口完成证据分类，有硬证据的差异修复可追溯，缺少采集的地方有明确说明。

## 5. 用户场景与验收
### US01 — 对照真实管理后台
#### AC-R001-01 — 按源表单保留字段标签、日期初值、单选和复选结
- Given 当前租户页面及已保存真实证据。
- When 打开相应页面并执行关联筛选或操作。
- Then 具有真实表单的代表页标签、控件和按钮保持来源顺序，日期不被表中最早时间覆盖。

#### AC-R002-01 — 下拉选项以当前租户当前页面上下文为优先，不借
- Given 当前租户页面及已保存真实证据。
- When 打开相应页面并执行关联筛选或操作。
- Then 在各租户解析销售、部门、账号和门店时，无跨租户捕获记录及明显异类选项。

#### AC-R003-01 — 表格列的宽度、对齐、可排序属性以对应采样为准
- Given 当前租户页面及已保存真实证据。
- When 打开相应页面并执行关联筛选或操作。
- Then 逐列DOM对比已采样表头，数字及空白列正确，无无依据分页、列设置或刷新。

#### AC-R004-01 — 不向每个统计页自动插入汇总卡；来源说明直接区
- Given 当前租户页面及已保存真实证据。
- When 打开相应页面并执行关联筛选或操作。
- Then 普通统计页无额外卡片，来源按钮可直接看出样本身份；本租户采样空与参考演示有明确区别。

### US02 — 下滑长表仍能辨认列含义
#### AC-R005-01 — 任意表格纵向滚动
- Given 任一登记租户中的普通表格、专用统计表、菜单树表或弹窗表格，且表身超过可见范围。
- When 在该表格所属滚动容器内持续向下滚动并到达表格末尾。
- Then 列标题停留在所属可见区域顶部且不被表身遮盖，直到该表退出可见区域；表格结束后不继续覆盖下一块内容或弹窗动作。短表无滚动时保持原布局。

#### AC-R005-02 — 多层表头、横向滚动和重新渲染
- Given 多行表头、宽表、嵌套滚动容器，或通过筛选/分页/展开后重新生成的表格。
- When 纵向和横向滚动、调整窗口、切换路由或重新查询。
- Then 全部表头行依顺序冻结且不互相覆盖；表头与表身同列保持对齐、横向移动同步；冻结范围属于当前表，不覆盖日历、下拉、菜单或其他弹层。排序/选择/焦点保持可操作，不多出重复可读表头。

## 7. 状态与交互
有证据默认态→筛选草稿→查询结果；日期无效保留上一结果；缺少样本→说明；读取失败→重试；编辑取消→不保存；本地保存→可恢复。控件保留focus、禁用、溢出、键盘与关闭状态。实际视觉待浏览器复核。表头在滚动跨过自身起始位置时进入冻结，在表格结束或表格销毁后停止显示；改变筛选、分页、树展开、尺寸或路由后重新按当前表几何生效。

## 8. 数据、权限与隐私
数据仅本地公开原型已脱敏样本；姓名沿用原已有员工名，客户和联系方式仍按公开包规则处理。来源指明本租户、参考租户或合成。导航和菜单可见性继续按既有本地权限规则。

## 9. 端与租户差异
只作用Admin。各租户保留菜单及字段差异，不把一个租户的采样下拉当作全局选项。
