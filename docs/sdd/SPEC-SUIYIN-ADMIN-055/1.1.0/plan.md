static-html，只有现有 HTML/CSS/JS 与本地数据；无认证、API、共享数据库或 migration；exception not-required、Operational Profile none。不进入生产仓。2026-09-20 房总最新指令“完整推送，并给陈宣宇在管理页代码仓建立 Issue 实现管理页销售变声统计的这个功能，提出环境深圳艺星，提出人ZHONG”授权本轮完整原型交付与销售变声统计工程建单。生产实施继续由目标代码仓正式工程流程完成。
## 3. 复用地图
复用现有表格、thead/th、共享外壳、通用列表和专用统计模块；优先在现有滚动容器内原生固定表头，必要适配保持最小。不得以复制假表格或改变数据来制造固定效果。
## 4. 文件与路由
仅 E:/AI 项目/佰智德三/碎银原型/suiyin-admin/prototype：共享表格 CSS、必要滚动几何辅助及 admin-content.html 加载；检查通用列表、使用/变声/AI/拉新等专用表、菜单树、领域内小表及弹窗表。具体文件由实现盘点确定并登记，不修改原始采集数据或业务模型。
## 5. 信息结构
保持原列名、列序、列宽、对齐、排序和多层表头。表格本身可见时，表头在所属滚动区域顶部可读；冻结背景遮住穿透的表身，层级低于日历/下拉/弹窗。短表的初始几何不变。
## 6. 交互实现
横向滚动同步列位置；多层表头累积自身高度，不相互遮盖。页面滚动、独立表身滚动、嵌套容器及弹窗滚动分别对待；表格末尾停止覆盖，切换路由或销毁表格清理辅助状态。排序、选择、分页、树展开、筛选重绘、窗口改变后仍有效。只冻结表头，不新增冻结列或额外工具。
## 7. Mock 方案
沿用已批准各租户样本及明确演示数据；不为制造长表而修改交付数据。确需检查多层/长表边界时使用隔离本地验证夹具，不把夹具当真实业务采集。
## 8. 验证计划
- 先枚举渲染结构/滚动容器种类，确保普通、专用、树表、局部小表和弹窗均有落点（R005）。
- 实际 Chrome 下滑测表头位置、前中末段的可见性；水平滚动测表头/表身列坐标相等，多行表头不重叠（AC-R005-01/02）。
- 筛选/排序/分页/树展开/路由重开与窄窗后复验；弹层不能被表头挡住，空/短表无无谓留白（AC-R005-02）。
- 共享影响检查保留各租户字段、数据来源与既有专用统计；本次证据保存 evidence/。历史 752 检查不能计作本轮冻结验收。
## 9. 风险与回退
祖先 overflow、iframe 页面、transform、边框合并和多重滚动区域可能使 sticky 无效，必须以真实滚动验证。避免所有表一刀切改固定高度，避免辅助表头截获交互；按修改清单和原 hash 回退。
## 10. 预览计划
复用 http://127.0.0.1:8169/prototype/_shell.html，在 Google Chrome 打开代表长表及弹窗并实际滚动。本轮完整推送同步 PRD、流程、设计规范、inline 和新版本 SDD；全管理页冻结只发布原型，工程 I001 只承接销售变声本页。
