# 西安画美与傲丽租户、碎银账号及菜单状态直改

## 1. 审核摘要

- **用户问题**：新增西安画美、傲丽后，管理页原型还不能切换到这两个环境；账号入口仍叫销售管理，指定医美租户仍出现上下班时间选项；隐藏菜单要先打开编辑弹窗。
- **完成后变化**：可选择两个新租户；所有租户的原销售管理入口改为碎银账号；全部艺星及画美、傲丽不再显示上下班时间设置；菜单表格可直接点“显示 / 隐藏”胶囊切换。
- **本次范围**：现有 Admin 静态原型；租户登记、账号页名称、指定租户的时间配置入口、普通菜单状态及同组件的平台菜单状态。
- **明确不做**：真实后台配置写入、生产端实现、修改账号权限或客户分配机制；本次已获完整推送及截图两功能建单授权，生产实现另走正式流程。
- **需要房总拍板**：无；房总2026-09-30回复“执行”，批准Q002直接保存及Q003待采集处理，Q001由用户正式网址解决。
- **AI 新提案**：以下均获房总“执行”批准。Q002：双段胶囊点选后立即保存本地并联动导航，点击已选项不重复写入，失败回滚；普通和平台菜单采用相同控件但保留各自作用范围。Q003：新租户复用后台公共框架，菜单按本租户来源登记；未采业务内容提示待采集，不套用艺星数据或专属能力。

## 2. 用户问题与预期结果

### 2.1 用户与场景

后台管理员切换企业、维护碎银账号，并调整本租户可见菜单。平台管理员在佰智德三的平台菜单定义中管理公共可见性。

### 2.2 用户问题

新租户缺少原型入口，无法评审自己的后台；“销售管理”不能准确表达用户要求的账号管理命名；指定租户出现不再需要的时间设置；逐项开弹窗修改显示状态增加操作步骤。

### 2.3 完成后用户能感受到的变化

能进入画美和傲丽各自环境；按“碎银账号”找到同一账号页；指定租户不再看到上下班时间配置；在菜单表格当前行直接决定显示或隐藏，并看到导航相应变化。

### 4.1 已发现冲突

1. 051和现行维护文档的15租户基线不含新环境；E001明确新增两租户。批准后本规格仅扩大这两个环境，不从其他平台注册表自动加租户。
2. 导航、菜单、账号内容和兼容链接依赖旧“销售管理”名称。必须以route/稳定身份同步迁移默认名称，保留其他字段和用户自定义名称，不做全仓“销售”文本替换。
3. 原型目前对所有租户补出04:00自动下班时间；E001对指定8个现有/新增样例删除时间配置。历史配置值保留但不再呈现或参与新表单提交，其他租户不受影响。
4. 菜单状态原需编辑弹窗；本规格把行内胶囊作为直接入口。原编辑弹窗读取同一状态并保持取消不保存，不能形成第二份状态。
5. 073的艺星专属辅助线及071回访规则不因“同为医美”自动扩散；新租户不复制深圳等租户权限、人员、部门或业务记录。
6. 新租户来源尚未采集，不能声称已复制真实后台。本次完整推送对当前文档作Source Convergence，历史版本快照不回写。

## 5. 用户场景与验收

### US01 — 切到新租户并打开账号管理

#### AC-R001-01 — 两个独立环境
- Given 原15租户及用户确认的两个正式标识。
- When 从企业切换器选择画美或傲丽，或从对应本地URL打开。
- Then 品牌和tenant正确，两者各出现一次；原15租户仍可访问，切换不写入其他租户存储。

#### AC-R002-01 — 缺失来源不冒充已采
- Given 新租户菜单、账号及业务数据尚未取得可读来源。
- When 查看新环境中尚未采集的区域。
- Then 明确显示待采集，区别于无数据；不借用其他租户的业务行或艺星专属权限。后续有本租户只读证据才按证据补齐。

#### AC-R003-01 — 改名覆盖且旧入口可用
- Given 各租户salesManage、旧sales链接、旧已开页签及原始默认菜单名。
- When 打开账号管理及相应菜单配置行。
- Then 默认名称均为碎银账号；route、身份、账号内容与原筛选/新增/编辑保持；旧链接仍进入同一页。明确用户自定义名按原语义保留。

### US02 — 指定医美租户不再配置上下班时间

#### AC-R004-01 — 两处入口与表单同时移除
- Given 六个当前艺星、画美、傲丽。
- When 逐个打开账号管理、系统设置及可达的新增/编辑弹窗。
- Then 不出现上下班时间输入、自动下班时间配置行或对应入口；旧存储不会重新补出04:00或旧时间，隐藏字段不参与新保存校验。

#### AC-R004-02 — 时间设置与其他业务的边界
- Given 其余9个现有租户及原来的上班记录、离开状态可转交和在线状态。
- When 比较改动前后页面与操作。
- Then 其余租户时间设置保留；指定租户只移除时间配置，不改变上述独立业务动作、记录和状态。

### US03 — 菜单表格直接选择显示或隐藏

#### AC-R005-01 — 胶囊选择
- Given 普通menu或bzds/allMenu的一行可编辑菜单。
- When 点击与当前不同的显示/隐藏选项，或用键盘聚焦后激活。
- Then 无需打开编辑弹窗即可提交该行选择；两个选项始终有文字、选中态和可见焦点，点击状态不触发拖动或树展开。

#### AC-R005-02 — 无变化与编辑同步
- Given 胶囊已选显示，或已保存隐藏。
- When 重复点击当前值，或打开后取消原编辑弹窗。
- Then 重复点击不保存、不增加记录；编辑回显同一真实值，取消不改值；其他编辑字段与树操作仍可用。

#### AC-R006-01 — 正确范围与父子限制
- Given 租户菜单、平台菜单及子菜单独立隐藏设置。
- When 隐藏/显示父节点，或试图在租户中显示一个被平台禁止的节点。
- Then 普通状态只影响本租户；平台状态按原规则限制所有租户；隐藏父级使整支导航隐藏，恢复父级不解除子项独立隐藏；平台约束不能被租户显示绕过。表中保留隐藏项以供恢复。

#### AC-R006-02 — 本地保存与导航恢复
- Given 同浏览器同源已开多个租户页面，包含将被隐藏的页签。
- When 保存菜单新状态并刷新/重开。
- Then 作用范围内窗口按既有规则更新导航；隐藏的当前页按原恢复路径关闭/转到可见页；刷新读回新状态；排序、父级覆盖及权限不被清空。

#### AC-R007-01 — 保存失败回滚
- Given 浏览器本地写入失败或读取到外部更新。
- When 尝试切换胶囊。
- Then 失败时恢复此前值及相关记录，不传播新导航、不报成功，提示可重试；外部更新先重新载入，不用过时整树覆盖其他修改。

#### AC-R008-01 — 表格与交付边界
- Given 既有普通六列表、平台九列表及滚动/拖动能力。
- When 在窄窗、纵横滚动和树折叠时使用胶囊。
- Then 表头冻结、操作列、拖动和树层级保持，控件不遮挡文字；反馈只声明浏览器本地效果，不请求真实业务API或产生真实后台写入。

### 7.3 进入、退出与恢复

- 入口：现有企业切换、salesManage、setting、menu、bzds/allMenu。

- 失败恢复：回原值，明确失败，允许重试；不存在真实网络业务请求或服务端成功状态。
