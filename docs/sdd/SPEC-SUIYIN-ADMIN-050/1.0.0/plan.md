## 2. Artifact Boundary

- **运行类型**：static-html。
- **为什么**：纯静态页面和本地JSON快照；临时HTTP服务只提供文件。
- **有状态信号**：无；浏览器中的已登录真实后台仅供只读取证，不属于目标运行时。
- **例外**：not-required。
- **Operational Profile**：none。
- **生产边界**：不进入Flutter / React / Go生产仓，不写真实后台配置。

## 5. 信息结构

- 左侧品牌区与真实侧栏；上部青绿栏、用户菜单；内容多页签。
- 企业切换只显示批准的15个，支持搜索，当前项标记并禁用。
- 菜单按真实DOM层级/顺序，平台定义补充route/variant，不显示工程术语。
- 未采集内容在页面正文说明“本页尚未完成对照”，并保留本租户/本页名称。
- 首屏保持当前默认深圳入口；用户可用page参数进入实际路由。
