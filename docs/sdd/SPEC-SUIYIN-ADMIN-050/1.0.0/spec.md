# 管理后台按真实租户配置还原导航与页面入口

## 1. 审核摘要

- **用户问题**：现有原型各企业共用同一套菜单和大量演示数据，名称、专用页面和入口与真实后台不符，房总无法准确对照各租户体验。
- **完成后变化**：进入哪个租户，就看到它自己的品牌、菜单顺序和实际页面版本；不会因同名菜单而打开错误版本，也不会把其他租户数据当作本租户快照。
- **本次范围**：L3 路线图的 S1：保留已明确的15个可进入租户，恢复 Shell、租户选择、导航层级、路由映射与采集状态隔离。内容页复刻由 S2–S4 逐份承接。
- **明确不做**：不更改线上菜单，不实现真实登录/API，不进入生产仓，不把平台全部48项选项自动纳入范围，不在本阶段复刻100条目录涉及的全部内容页。
- **需要房总拍板**：无。房总于2026-09-18明确“碎银私域这个也不要，剩下的就可以执行了”，批准本合同并排除sysy。
- **AI 新提案**：R006 对未采集页面显示明确状态；R007 用独立本地 URL/浏览器页签承接真实后台的“切换环境另开页”行为，保留旧租户页签上下文。

## 2. 用户问题与预期结果

### 2.1 用户与场景

- 用户：房总及管理后台原型评审者。
- 场景：对照已登录的真实后台，切换租户检查页面与 Mock。
- 当前做法：Shell 注册44页、16个旧租户，注释写明多数企业共用菜单/页面/数据；这不是本次保留的15个租户集合。

### 2.2 用户问题

同名入口有不同的真实路由；不同企业的菜单分配、可见性、排序不同。单看深圳菜单或共用全量平台目录都会制造不存在的入口；仅切标题还会留下其他企业的数据。

### 2.3 完成后用户能感受到的变化

能从与真实后台一致的企业入口找到对应页面，清楚区分已按实况采集的内容和仍未核对的内容。

### 2.4 成功信号

### 4.1 已发现冲突

1. 旧16租户列表与本轮15租户集合不同。E002决定本次范围，不能只比较数量。

## 5. 用户场景与验收

### US01 — 在保留租户间准确进入管理页

- 用户：房总。前置：本地静态预览。目标：选择真实企业，看到该企业导航。独立价值：先确保对照对象正确。

#### AC-R001-01 — 范围与身份准确
- Given 本地企业选择器已打开。
- When 对照 scope-decision.json。
- Then 保留集合逐项相等，已排除/跳过企业不出现；云柯九里对应瑞熙小刘，瑞熙酒店对应瑞熙小温，不能猜测域名。

#### AC-R002-01 — 记录同名菜单的不同版本
- Given 平台目录存在两个“群发管理”。
- When 建立路由映射。
- Then massMessageList 与 massMessageListYx 是独立记录；深圳进入已分配艺星版，锦帛保留两个入口，不按中文名称合并。

#### AC-R003-01 — 按租户实况生成菜单
- Given 某租户分配树、显示/排序表及实际侧栏已采集。
- When 打开该租户。
- Then 层级、顺序、标签、入口版本与其实际侧栏一致；不加入仅存在于平台目录的未分配项。

#### AC-R004-01 — 当前账号边界
- Given 某平台项已分配但实际侧栏不出现。
- When 核对可见菜单。
- Then 保存配置与实际显示的差异，本次复刻使用实际可见结果；不能写成该租户没有数据或所有角色无权限。

#### AC-R007-01 — 切换环境保留来源上下文
- Given 深圳页签打开消息占比，用户在企业菜单选择锦帛。
- When 执行本地环境切换。
- Then 打开携带锦帛身份的独立本地页面；深圳页面保持原租户和筛选，锦帛不带入深圳页签/列表数据。

#### AC-R007-02 — 浏览器阻止新页
- Given 浏览器未打开目标页。
- When 用户点击租户入口。
- Then 显示可重新点击的本地目标链接，不显示已切换成功，不覆盖当前企业数据。

### US02 — 可靠地区分真实快照与采集缺口

- 用户：评审者。前置：导航可用。目标：不会把旧通用样本或空态当真实租户数据。

#### AC-R005-01 — 数据有独立归属（来源策略由051 R003/R006承接）
- Given 两租户具有同一路由。
- When 切换和刷新各自预览。
- Then 数据以租户、路由、筛选及采集快照标识联合定位；来源不跨租户，数字不自动按倍数或随机生成。

#### AC-R006-01 — 未采集与空数据分开（S1阶段历史，当前按051 R001/R010）
- Given 某可见菜单尚未完成内容采集。
- When 进入该菜单。
- Then 显示“本页尚未完成对照”；不使用其他租户/通用 Mock，不显示“暂无数据”。只有真实查询返回空结果才能展示业务空态。

#### AC-R006-02 — 缺失本地快照
- Given 已登记页面的本地快照无法读取。
- When 页面加载失败。
- Then 显示“快照读取失败，请重试”并保留租户身份；无权限、缺采集、空数据分别记录。

#### AC-R008-01 — 静态边界
- Given Chrome 打开本地原型。
- When 检查网络与模拟动作。
- Then 数据来自本地快照，不发后台认证/API请求，不下载或运行客户端，不把本地操作反馈为线上成功。

#### AC-R009-01 — 状态与视觉
- Given 各租户菜单在正常宽度和窄窗口打开。
- When 展开、滚动、键盘聚焦、选择、关闭菜单、返回内容页。
- Then 无遮挡/截断关键名称，展开和选中有文字或结构状态，焦点可见；与对应真实截图在同尺寸人工比较后才能称视觉完成。
