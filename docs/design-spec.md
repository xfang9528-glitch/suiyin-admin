## 证据与适用范围

当前登记 15 租户、765 个页面入口、85 种路由；AI费用统计覆盖已有 AI 管理父级的 13 个租户。2026-09-18 保存的 UI 资料覆盖 61 种路由、19 种编辑弹窗、2 种整页编辑；65 个菜单名称、64 个按钮名称拥有 SVG 映射，这些数量不是唯一图形数，也不表示所有租户已采集。

结构以本租户本路由的原始采集为先，其次使用明确标识的参考结构。`data/live-ui-reference.js` 提供来源几何，`data/form-schemas.js` 保留安全表单结构，`data/button-states.js` 提供采集按钮状态，专用模块保留各页面语义。不能因为存在共用 CSS 就推断所有路由颜色、字段、排列或交互相同。

- 深圳品牌为 18px、2px 字距；客户端采样页脚版本为 v2026091804。该版本是来源画面字段，不是原型发布 tag；不改变其他租户的采样版本。
- 060@1.1.0：侧栏展开、滚动、收起状态、已开页签及菜单树折叠/纵横滚动按浏览器本地状态保留，刷新和重开恢复；截图未出现的旧采集菜单不能直接删除，新变声菜单仍按已批准范围保留。
- 068@1.0.0：先由本租户完整库存和平台当前默认结构生成有效树，再覆盖租户明确调整的同级列表顺序及被跨组移动项的父级；菜单表与可见导航共用此树。一级排序不冻结二级组，组内排序不冻结未移动项的父级；新进入成员按平台有效顺序追加，缺失项不造节点。平台当前祖先链的隐藏、删除和租户原权限独立限制可见性，跨组不能绕过；平台显示不解除租户独立隐藏。目标父级失效时保留覆盖、提示并暂用默认归属，恢复有效后重新应用。切换租户新开对应本地页面，弹页受阻提供链接。

平台菜单按 [060@1.1.0](sdd/SPEC-SUIYIN-ADMIN-060/1.1.0/spec.md) 保留九列及 1320px 最小宽度，空备注仍为空，允许水平滚动。名称左侧手柄拖动，一级携带全部二级，二级可组内/跨一级移动；同层顺序自动编号，编辑/新增不输入排序号。合法落点、悬停展开、边缘滚动、键盘与触控等价；取消无写入，成功本地保存并可撤销最近移动，失败回滚。侧栏即时联动且保留仍可见页面；本地状态恢复、保存/失败提示真实，刷新不重置。父级级联阻止循环；普通菜单名称只读规则不外推给平台新增表单。

## 筛选、日期与操作

控件一般高 32px、圆角 4px、14px 文字。普通按钮内边距 8px 15px；具体页面来源可覆盖。开关 40×20px、圆点 16px，开启蓝、关闭灰。

字段标签、顺序、单选/复选、日期初值、按钮位置与禁用状态依本页来源，不从表格最早日期猜初值，不把 radio 的内部值当日期。没有来源的快捷日、查询或重置不普遍增加。

实体下拉按当前租户和页面上下文取值；不从参考表格或别的租户借入销售、部门、账号、门店。枚举与业务实体分开。保留搜索、清空、禁用项、回填、Escape 和溢出行为，缺少选项时说明未采集。

日期为可输入文本与共用静态日历，单日一个月，区间两个月。起止作为整体控件布局，手工输入可校验；首次范围选择不自动提交查询，Escape 或外部点击取消未完成选择，重置清除旧弹层。销售使用与销售变声统计完整共用单日/范围分段、日期输入和弹层。单日一个输入，范围两个输入；范围切回单日取开始日并归并起止。模式或输入只修改草稿；快捷日立即查询且保留模式，重置回单日今天并提交。两页日期初值分别来自本租户快照日与合成事件运行日，不能为视觉一致改写来源。

## 列表和统计表

列宽、对齐、是否可排序依对应采样 profile；数值按来源对齐，不一律居中。空字符串与空白弹性列保留为空，不补破折号或详情链接。批量按钮在未选择时禁用。只在来源存在时显示分页、刷新、列设置、查询和选择，不向普通统计页插入推算的汇总卡。预约记录依据房总明确要求和 [062@1.0.0](sdd/SPEC-SUIYIN-ADMIN-062/1.0.0/spec.md) 增加一个预约总量及柱线组合图，这是本页显式例外，不推广到其他统计页。

销售使用统计采用专用六列表：72 / 234 / 270 / 212 / 232 / 弹性列；消息数、聊天好友数右对齐。正文行约 40.1px，只保留横向边线；部门为 20px 高的蓝色标签（背景 #ecf5ff、边框 #d9ecff、文字 #409eff）。同销售跨部门用组与 rowspan 表示，多部门有小计，小计背景 #f6f8fa，tfoot 全表合计保留在最后。排序整组移动，不拆散明细；没有分页。

使用统计标题、使用人数和合计在同一统计区域，结果框距筛选下沿 18px、左右 8px、内边距 16px。筛选为单行，控件 32px 高；单日/范围及今天/昨天/前天为相邻分段按钮，选中使用 #00c4af。单日日期与部门宽 220px，范围日期宽 350px；重置不添加图标。去掉固定高度内表滚动，剩余双层滚动行为仍待实站复核。

销售变声统计完整复用使用统计筛选的字段、顺序、分段、日历、快捷日、部门与搜索/重置/导出，颜色、图标、尺寸、间距和交互反馈一致。同日期同视口的单日/范围筛选截图分别字节一致，见本轮验证记录。业务列仍是序号、销售、部门、变声使用次数，保留次数排序、20 条默认分页及全筛选导出；使用统计的消息/好友列及无分页结构不迁入变声页。

所有当前 Shell 管理表格表头在所属滚动可见区域顶部冻结，覆盖普通列表、专用统计、菜单树表、小表与弹窗表格。多层表头整体冻结且不互相覆盖；横向滚动时与正文同步保持列对齐，现有固定操作列维持原行为。表头不越过本表底部，表格退出后不悬留遮住下一块内容。排序、选择、焦点、重绘和窗口变化均保持可用；日历、下拉、菜单及弹窗层级高于被冻结的背景表头。短表不造滚动，空态不造行，不更改字段、列宽、行高和分页。

模型名沿用深圳星瞳/星鉴/星程/星语和其他来源的碎银·用途命名，画像与上下文可共用一个模型；无版本不造版本。10份参考配置只作为演示配置，不声称真实历史调用、自研基座、租户独占或定向训练。金额未知、真实零、小于0.01元、项目归类不完整与缺日期分别表达；客户费用不混入供应商成本。详见 [费用产品说明](../prd/ai-cost-stats.md)。
