# 碎银管理后台现行设计规范

更新：2026-09-20。基线为 051@1.1.0；销售变声统计执行 052@1.1.2，销售使用统计执行 053@1.0.1，全管理页对齐执行 054/055/056@1.0.0。本轮按 [四页发布勘误](sdd/pixel-correction-20260920.md) 恢复截图已确认的呈现与来源边界。本文替代旧主按钮一律青绿、通用列表和统一分页等推断；不改变各业务统计口径。

## 证据与适用范围

当前登记 15 租户、752 个页面入口、84 种路由。2026-09-18 保存的 UI 资料覆盖 61 种路由、19 种编辑弹窗、2 种整页编辑；65 个菜单名称、64 个按钮名称拥有 SVG 映射，这些数量不是唯一图形数，也不表示所有租户已采集。

结构以本租户本路由的原始采集为先，其次使用明确标识的参考结构。`data/live-ui-reference.js` 提供来源几何，`data/form-schemas.js` 保留安全表单结构，`data/button-states.js` 提供采集按钮状态，专用模块保留各页面语义。不能因为存在共用 CSS 就推断所有路由颜色、字段、排列或交互相同。

## Shell 与菜单

- 顶栏 60px，品牌区和侧栏宽 240px；一级导航行 56px，二级 50px；使用来源 SVG。
- 内容距侧栏右缘 20px，页签高 40px，页签与内容间距 15px。文档根、工作区与内容 iframe 的空余背景统一为白色，避免短页下方露出灰底。窄窗保留侧栏收起、遮罩、焦点和页签关闭重开。
- 深圳品牌为 18px、2px 字距；客户端采样页脚版本为 v2026091804。该版本是来源画面字段，不是原型发布 tag；不改变其他租户的采样版本。
- 侧栏展开、滚动和已开页签按会话状态保留；截图未出现的旧采集菜单不能直接删除，新变声菜单仍按已批准范围保留。
- 可见导航读取本租户显示配置与本地覆盖；完整菜单库存独立保留。切换租户新开对应本地页面，弹页受阻提供链接。
- DR-095 要求数据展示新增项同步菜单管理及已有平台定义；稳定身份、名称、路由、父级保持一致。隐藏、排序及已有权限变更只影响本租户。

普通菜单列为名称、超级权限、状态、排序、空白弹性列、操作。保留树、开关、文本状态、固定右操作和空白，不增加通用筛选、分页、刷新或列设置。编辑蓝、删除红、记录灰；窄排序框 84px，但保留数值可读性，不照搬源页输入宽度异常。

平台菜单保留九列及 1320px 最小宽度，空备注仍为空，允许水平滚动。父级级联阻止循环；普通菜单名称只读规则不外推给平台新增表单。

## 筛选、日期与操作

控件一般高 32px、圆角 4px、14px 文字。普通按钮内边距 8px 15px；具体页面来源可覆盖。开关 40×20px、圆点 16px，开启蓝、关闭灰。

字段标签、顺序、单选/复选、日期初值、按钮位置与禁用状态依本页来源，不从表格最早日期猜初值，不把 radio 的内部值当日期。没有来源的快捷日、查询或重置不普遍增加。

实体下拉按当前租户和页面上下文取值；不从参考表格或别的租户借入销售、部门、账号、门店。枚举与业务实体分开。保留搜索、清空、禁用项、回填、Escape 和溢出行为，缺少选项时说明未采集。

日期为可输入文本与共用静态日历，单日一个月，区间两个月。起止作为整体控件布局，手工输入可校验；首次范围选择不自动提交查询，Escape 或外部点击取消未完成选择，重置清除旧弹层。共享日历不决定页面是否显示日期模式：销售使用统计保留单日/范围，销售变声统计仅直接区间。

## 列表和统计表

列宽、对齐、是否可排序依对应采样 profile；数值按来源对齐，不一律居中。空字符串与空白弹性列保留为空，不补破折号或详情链接。批量按钮在未选择时禁用。只在来源存在时显示分页、刷新、列设置、查询和选择，不向普通统计页插入推算的汇总卡。

销售使用统计采用专用六列表：72 / 234 / 270 / 212 / 232 / 弹性列；消息数、聊天好友数右对齐。正文行约 40.1px，只保留横向边线；部门为 20px 高的蓝色标签（背景 #ecf5ff、边框 #d9ecff、文字 #409eff）。同销售跨部门用组与 rowspan 表示，多部门有小计，小计背景 #f6f8fa，tfoot 全表合计保留在最后。排序整组移动，不拆散明细；没有分页。

使用统计标题、使用人数和合计在同一统计区域，结果框距筛选下沿 18px、左右 8px、内边距 16px。筛选为单行，控件 32px 高；单日/范围及今天/昨天/前天为相邻分段按钮，选中使用 #00c4af。单日日期与部门宽 220px，范围日期宽 350px；重置不添加图标。去掉固定高度内表滚动，剩余双层滚动行为仍待实站复核。

销售变声统计复用纠偏后的按钮、日期和数值外观，保留已批准的次数排序、20 条默认分页及全筛选导出。业务列是序号、销售、部门、变声使用次数；不复制使用统计的消息与好友字段，也不复制日期模式。

## 四页专用呈现

- **深圳拉新记录**：32px 控件；日期 260px、微信号 240px、重复添加/好友状态各 120px。查询、重置、绿色描边导出位于第二行。七列表格充满余下视口，白色空态和右下分页保留。列宽按当前实测结果，不复用销售使用表；好友弹层与触发器对齐。微信号及重复添加仅展示已采选项，不能补猜。
- **消息占比**：筛选单行，日期 350px、自然日 100px、微信号 240px；下方单卡片内含 16px 标题、28px 总量和图表，图例置顶。四类柱形、红色折线和完整日期轴按采样绘制，图例切换和提示保留，不从柱高推断未采数值。
- **AI 辅助统计**：快捷日期置前，单行筛选可真实水平滚动；日期 320px、部门 140px、账号关键词 180px。控件约 24px，维度为相邻分段按钮，绿色搜索为 #07c160。九列表格以灰表头、约 41.8px 正文行和水平边线呈现；销售名加粗，多部门以灰色多行标签显示，辅助率含绿色进度条与百分比。截图部分样本说明放于结果末尾，不另加顶部标题或汇总卡。

以上数值对应本轮截图测量及当前实现，只证明已观察的默认视图；边缘误差、排序图标、字体栅格和滚动细节仍按验收记录继续迭代。

## 领域布局与编辑

- 聊天：全部聊天与销售接待查询各自保留筛选及初态；销售接待未查询前不显示伪造结果。演示会话显式区分。
- 销售统计：恢复 12 指标、4 排行及相应图表槽；8 处明细未采集的图表显示说明，不绘制猜测走势。
- 配置：依来源保留表单和确定操作，不自动附加双栏预览、保存/撤销或重复统计维度。
- 预约：协议、资料完整性、项目和同步配置分区保留，独立操作分别保存；0 和透明色是合法值。部分 checked 未采集时注明本地默认。
- 好友：普通与艺星路由按来源安排顶部操作、筛选和独立关键词区。未采集的四类信息、高级筛选展开和所在账号选择不得被旧独立页的演示替代。
- 话术：搜索按搜索或 Enter 提交，树父子关系未采集时说明边界。
- 普通菜单编辑为视口 50% 宽三列、标签宽 140px；平台编辑 800px 两列、间距 20px；只读记录没有提交 footer。
- 专家和案例使用整页编辑，专家七天、32 半小时时段；案例图片卡 180px/图片区 120px、排序 150px、正文编辑区 560px。富文本是静态交互，不是原编辑器完整引擎。
- 版本表单保留已采集平台、状态、强更与文件选择，不真实发布客户端；推断表单明确标记本地演示。

## 状态与验收

来源按钮直接区分本租户采样、参考租户和合成演示。未采集、采集时加载中、确认空态、当前查询无样本、加载失败和无权限分别表达；失败不能变成全员 0。取消不保存，危险操作指明对象及影响范围，所有反馈诚实说明本地效果。
