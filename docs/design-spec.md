# 碎银管理后台现行设计规范

更新：2026-09-19。当前主线依据 SPEC-SUIYIN-ADMIN-051@1.1.0 和 2026-09-18 原网页 DOM/计算样式/展开界面。旧公众号与微信绿方案见 docs/history/before-admin-live-reference/，不得与当前 Shell 混用。

## 来源与适用范围

本次 UI 采样覆盖61条路由、19种编辑弹窗、2种整页编辑。SVG 映射为65个菜单名称、64个按钮名称，不代表唯一图形数。以 admin-live-ui.css、data/live-ui-reference.js 及专用页面样式为实施来源；没有独立字体文件，使用原站字体栈。跨租户复用组件不等于跨租户复用真实身份数据。

## Shell 几何

- 顶栏60px，白色品牌区与侧栏同宽240px；顶部其余区域青绿。
- 一级导航行56px，二级50px；图标使用原网页 SVG，不能用 Emoji 替代。
- 内容区相对侧栏右边缘留20px；页签40px，内容与页签留15px。
- 页面可见性按本租户配置与本地覆盖生成；完整菜单库存独立保留。
- 租户切换开独立本地页面，当前项禁用；被浏览器阻止时提供可点击链接，不能覆盖原租户上下文。
- 窄窗侧栏使用已有收起/遮罩状态；焦点可见。页签可关闭和重开。

## 常规控件

输入和普通按钮32px高、4px圆角、14px文字。按钮一般8px 15px内边距；链接动作按源页面专用尺寸。下拉支持实际选项、单选/多选、搜索、清空、回填、禁用项和 Escape。不要把禁用项从清单删除。

开关40×20px，圆点16px，关闭 #dcdfe6，开启 #409eff。输入 focus 用 #409eff。数字步进器按来源限制，菜单排序可为负数，不因通用组件默认 min=0 截断。

常规表格按来源列宽/可排序状态渲染，固定操作列与水平滚动；分页基于本地样本，不冒充线上总量。只有原站需要的页面才有查询、分页、选择和排序。树、图表、配置、聊天、卡片必须用各自结构，禁止用统一列表代替。

## 菜单管理专用结构

以下对照在同租户、1480×1540 CSS 像素视口下测得。

| 对象 | 原站与原型值 |
|---|---|
| 标题区 | x260 / y125，1200×64 |
| 表格顶点 | x260 / y209 |
| 表头 | 39.8px |
| 首行 | 57.4px |
| 普通菜单六列 | 200 / 150 / 150 / 150 / 弹性400 / 150px |
| 层级缩进 | 每级16px；占位/箭头区域20px |
| 行操作 | 12px文字，SVG12px；单按钮17.6px高，2px内边距 |
| 编辑按钮实测 | x1322 / y256.8，44.9375×17.6px |

六列依次为菜单名称、超级权限、菜单状态、排序、无标题弹性列、操作。弹性列为空，不放破折号。表格保留内部滚动、覆盖式滚动条、树展开及固定右操作；没有通用查询栏、分页、列设置或刷新按钮。标题区左侧3×14px青绿标记，右侧全部记录。

操作文字：编辑蓝、删除红、记录灰。操作区在来源宽度下可将记录换到第二行，不裁剪右侧按钮。菜单状态显示为文本，不改成彩色 Tag。保留真实显示/隐藏和排序值；深圳、成都等配置不同，不按截图一边强行覆盖另一租户。

平台菜单具有自己的九列最小宽度1320px，允许水平滚动；树、空备注、固定操作仍按来源。父级级联显示根/子项，禁止自身或后代形成循环，改变属性不应无故改变树顺序。

## 弹窗与整页编辑

- 普通菜单：宽度视口50%，三列，标签宽140px；菜单名称只读，状态单选、超级权限开关、排序步进；确认后取消的按钮顺序按来源。
- 平台菜单：800px、两列、20px间隔；名称、平台名、唯一标识、状态、路由、图标、父级、排序、备注、类型按来源排列。
- 全部编辑记录：视口宽80%；本轮1184×1328.6px、左148/上105.7；表头为时间/编辑人/类型/字段/旧值/新值。只读无提交 footer，分页独立。
- 删除：指明对象与影响范围，取消不变更；只修改本地演示。
- 普通菜单窄排序框按来源84px绘制，但保留数值可读性；原站该视口内部输入宽0导致裁字，这一缺陷未照搬。
- 专家、案例采用整页编辑而非统一弹窗；专家七天、32个半小时时段。案例图片卡180px/图区120px、排序150px、正文编辑区560px。
- 富文本标题/字号/字体/行高下拉为6/13/14/7项，工具栏附近展开。静态实现不等于移植原站完整编辑器引擎。
- 版本表单保留8类平台、3种状态、强制更新、下载地址、本地文件选择；不会真实发布客户端。

## 状态与验收

默认、hover、pressed、focus-visible、selected、disabled、loading、成功、无结果、错误、溢出、取消、危险确认分别检查。只读弹窗无冗余提交 footer；表单保存/取消有明确本地结果。无数据不等于加载失败或无权限。

54项菜单和22项流程回归证明对应操作；737项数据检查不证明视觉。人工对照已覆盖菜单/平台菜单、相关弹窗及部分代表业务页面，其他路由没有逐页像素一致结论。范围、证据和资源缺口见 docs/verification/admin-live-reference.md。
