# 好友列表 PRD

## 模块位置
- 菜单：好友管理 → 好友列表
- 路由：`/friend/list`
- 原型文件：`prototype/friend_list_v1.0.html`
- React 组件：`suiyin-admin-react/src/pages/FriendListPage.jsx`

## 功能概述

好友列表页展示所有微信好友数据，支持按分类筛选、关键词搜索、批量操作。是好友管理模块的核心页面。

## 页面结构

### 1. 分类Tab区（顶部）
- 5 个下拉按钮：全部好友 / 来源信息 / 好友信息 / 用户信息 / 购买信息
- 点击按钮展开 Popover 弹窗，显示分类统计卡片

### 2. 全部好友弹窗（Popover）
- **顶部**：全部好友总数（如 2033 人），绿色边框高亮卡片
- **待转化区**：新好友 / 有信息好友 / 有销售好友 / 有购买好友
- **重要区**：复购好友 / 升级购好友
- **裂变好友区**：裂变邀请好友
- 每张卡片显示分类名称 + 人数
- 点击卡片切换筛选条件

### 3. 筛选栏
- 关键词搜索（姓名/手机号/微信号）
- 重复好友开关
- 接待中销售下拉
- 专属销售下拉
- 操作按钮：查询 / 重置 / 导出表格 / 回收站

### 4. 数据表格
- **列**：复选框 / 好友信息（头像+昵称+微信号）/ 人设号 / 接待销售 / 专属销售 / 来源渠道 / 添加时间 / 好友标签 / 手机号 / 用户姓名 / 历史消费 / 最近购买 / 用户备注 / 操作
- **操作列**：分配 / 详情
- **底部**：分页器 + 批量操作栏（选中 N 人：批量分配 / 批量标签）
- 支持行选择（checkbox）

## 数据说明
- 好友总数典型值：2000+
- 默认分页：10条/页，支持切换 10/20/50
- 按添加时间倒序排列

## 交互细节
- Tab 下拉弹窗：点击按钮展开，点击关闭按钮或点击弹窗外部关闭
- 弹窗最小宽度 480px，防止分类卡片换行
- 表格支持横向滚动（scroll-x）
- 选中行高亮
