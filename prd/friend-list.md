# 好友管理产品说明

更新：2026-09-20。当前 Shell 使用 `customerManagement` 与 `yxCustomerList`，按各租户真实菜单选取路由。行为和界面对齐依 051@1.1.0、055/056@1.0.0，见 [主 PRD](admin-live-reference.md)。旧 `/friend/list`、`friend_list_v1.0.html` 和 PC 筛选移植文档已转为 [历史记录](../docs/history/before-admin-wide-alignment/README.md)，不作为当前 Shell 的完整展开规范。

## 用户结果

评审者可以核对同租户好友页的已采集字段、顶部操作、列表和搜索；未采集的选项或展开状态直接说明，避免把一个租户或 PC 端的演示当成当前管理页实站。

## 当前页面结构

| 页面 | 已恢复结构 | 缺证据处 |
|---|---|---|
| 普通好友管理 `customerManagement` | 按来源保留全部好友、来源信息、好友信息、用户信息、购买信息、创建虚拟好友、全部记录等已采集入口；列表、筛选和行操作使用本租户结构 | 分类入口的完整 Popover 内容未采集，点击说明边界，不编造分类人数与规则 |
| 艺星好友 `yxCustomerList` | 按来源保留导出表格、全部记录、初态筛选、展开入口、重置/执行筛选及独立好友关键词区域 | 高级筛选展开未采集；所在账号的单/多选类型与选项未知，禁用占位并解释 |

这里只在来源有相应按钮时恢复，不要求所有租户拥有同样的操作。已采集搜索框提示为「昵称 / 备注名 / 手机号 / 卡号」；其位置与动作独立呈现，但不能据此承诺旧独立页所有筛选和搜索组合语义都已重新实站验证。

## 操作与状态

- 查询以已提交条件过滤本地可用样本；重置恢复当前页来源默认值，不重复插入顶部操作或搜索区。
- 销售、部门、分组和账号等实体选项来自当前租户及页面；缺选项不从其他租户补齐。
- 表格字段、对齐、空白、是否可分页及选择按来源；未选中记录时适用批量操作禁用。
- 已实现的本地创建、编辑、记录和删除沿用来源动作及确认/取消；反馈明确只改变静态原型。
- 参考样本、合成演示、确认空态、未采集与读取失败分开标识。未采集的展开动作只提示尚未采集，不伪造执行成功。

## 验收与边界

本轮好友专项 156/156 指定结构及重置检查通过，属于 DOM 和交互证据。当前 Chrome 不可用，尚无最新实站逐像素与完整展开验收；详情见 [验收摘要](../docs/verification/admin-live-reference.md)。既有 23 维 PC 级联、固定默认分页、合成分类人数及所有高级条件都可过滤等旧承诺不适用于当前主线。
