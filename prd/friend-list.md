# 好友列表 PRD

## 模块位置
- 菜单：好友管理 → 好友列表
- 路由：`/friend/list`
- 原型文件：`prototype/friend_list_v1.0.html`
- React 组件：`suiyin-admin-react/src/pages/FriendListPage.jsx`

## 功能概述

好友列表页展示所有微信好友数据，支持按分类筛选、关键词搜索、批量操作。是好友管理模块的核心页面。

## 页面结构

### 1. 分类Tab区（顶部）
- 5 个下拉按钮：全部好友 / 来源信息 / 好友信息 / 用户信息 / 购买信息
- 点击按钮展开 Popover 弹窗，显示分类统计卡片

### 2. 全部好友弹窗（Popover）
- **顶部**：全部好友总数（如 2033 人），绿色边框高亮卡片
- **待转化区**：新好友 / 有信息好友 / 有销售好友 / 有购买好友
- **重要区**：复购好友 / 升级购好友
- **裂变好友区**：裂变邀请好友
- 每张卡片显示分类名称 + 人数
- 点击卡片切换筛选条件

### 3. 筛选栏（2026-06-18 改：艺星租户换成 PC 群发选好友·第一步同款 CRM 筛选）
> 房总要求：艺星租户好友列表筛选 = PC 端（suiyin-pc-chat）群发「选择好友」向导**第一步「筛选选中」**那套 CRM 筛选，1:1 复用其 `bc-fp-filters` DOM/CSS/JS。原「关键词 / 重复好友 / 接待中销售 / 专属销售」简单筛选已替换（第一步没有这些项）。

- **顶部工具条**：全部好友总数卡（993,226 人）+ 导出表格 / 保存为标签 / 全部记录 / 创建虚拟好友
- **CRM 筛选（21 维，4 列网格，默认收起仅显前 8 项）**：
  - 折叠区（前 8）：所在账号（渠道→人设号两列级联，含搜索 + 全选 + Shift 区间多选）/ 等级 / 等级(AI) / 第一需求(AI) / 有电话 / 状态 / 末次咨询日期 / 添加日期 /（第 9 起为展开区）第二需求(AI)
  - 展开区：地区（省/市/区三级级联）/ 建档日期 / 开发人 / 客服经理 / 会员等级 / 未次预约日期 / 建议改善 / 用户特征 / 推荐设备-材料 / 推荐医生 / 喜好风格 / 末次回访日期
  - 多选项展示为标签（最多 3 个 + `+N` 折叠）；单选项点选即关
  - 展开/收起切换；操作按钮：重置 / 搜索
  - 日期选择器：PC 用 `wxDatePicker`，admin 本页无该组件 → 退化为原生 `<input type=date>`（功能等价，样式接近）
- **布局**：因 CRM 筛选高度随展开/收起变化，本页由固定定位改为自然流式滚动布局

### 4. 数据表格
- **列**：复选框 / 好友信息（头像+昵称+微信号）/ 人设号 / 接待销售 / 专属销售 / 来源渠道 / 添加时间 / 好友标签 / 手机号 / 用户姓名 / 历史消费 / 最近购买 / 用户备注 / 操作
- **操作列**：编辑 / 删除 / 记录
- **底部**：分页器 + 批量操作栏（批量删除 / **批量分组**）
- 支持行选择（checkbox）；**表头复选框 = 全选当页**

### 5. 批量分组（2026-06-18 新增）
- 入口：底部批量操作栏「批量分组」按钮（在「批量删除」右侧）
- 未勾选好友点击 → toast「请先勾选好友」拦截，不弹窗
- 弹窗：分组名**组合框**，沿用 PC 端 DR-028「话术名称组合框」逻辑——
  - 输入关键字 → 实时过滤匹配已有分组
  - 点候选即选中；**无完全匹配项时末尾出现绿色「＋ 创建「XXX」」**，点击即输即建（直接敲完整新名字点确定也算新建）
- 确定 → 关弹窗 + toast「已将 N 位好友分组到「XXX」」
- 已有分组 mock：高意向客户 / 到院未成交 / 水光针意向 / 玻尿酸意向 / VIP 客户 / 需回访 / 抖音来源 / 点评来源（实际接后端好友分组接口）

## 数据说明
- 好友总数典型值：2000+
- 默认分页：10条/页，支持切换 10/20/50
- 按添加时间倒序排列

## 交互细节
- Tab 下拉弹窗：点击按钮展开，点击关闭按钮或点击弹窗外部关闭
- 弹窗最小宽度 480px，防止分类卡片换行
- 表格支持横向滚动（scroll-x）
- 选中行高亮
