# 各租户菜单拖动与本租户导航联动

行为合同：[SPEC-SUIYIN-ADMIN-068@1.0.0](../docs/sdd/SPEC-SUIYIN-ADMIN-068/1.0.0/spec.md)。提出环境佰智德三，提出人房昕；管理页PC。工程执行范围和交接以同包Handoff/Test Contract为准。

租户管理者整理「系统管理 → 菜单管理」时，直接把菜单拖到需要的位置；菜单表和本租户左侧导航一起变化。无需逐项填写数字，也不会在保存后被平台旧顺序弹回。覆盖当前注册的全部17个原型租户，佰智德三的普通menu和平台allMenu各自保留作用范围；17租户是原型验证清单，不是生产白名单。

## 操作与可见结果

- 当前17个租户的普通menu六列显示为「菜单名称、仅超级管理员可见、菜单状态、顺序、空白弹性列、操作」。2026-09-30将原「超级权限」表头统一显示为「仅超级管理员可见」，该列由150px加宽到180px，保持单行；其他列宽与控件布局保留，空白列按剩余空间伸缩。本次只调整展示文案，内部字段仍为「超级权限」，既有开关值、权限语义、导航过滤和按租户隔离的本地保存不变。名称前增加独立拖动手柄；顺序按完整同层库存只读显示1…N，编辑提示“由列表拖动调整”。普通菜单名称仍只读；状态按[076@1.0.1](../docs/sdd/SPEC-SUIYIN-ADMIN-076/1.0.1/spec.md)改为表内「显示 / 隐藏」胶囊，直接保存，失败恢复原值与记录。同值点击不写入，编辑弹窗共用同一状态；权限、删除与记录保留原范围。
- 一级拖动带走全部子项；二级可在组内排序或拖入另一一级。直接落在一级上追加末尾，空一级成为首项，移空的一级留在库存。自身带页面的一级接收子项时保留原页面，不新增重复路由。
- 落点提供插入线、目标文字与分支拖影；悬停收起的一级自动展开，长表边缘自动滚动。键盘、桌面触控和鼠标都可操作，冻结表头和行操作保持可用。
- 成功后提示“已保存，本租户导航已更新（本地原型）”，同租户已开窗口及时更新，仍可见业务页及页签、输入状态保留。其他租户配置和平台定义不受本租户移动影响。

胶囊支持键盘焦点和激活，点击不触发拖动或树展开。普通状态仅影响本租户，平台/父级限制与子项独立隐藏继续生效；点显示不代表绕过限制。见[状态流程](../flowcharts/admin-account-menu-status.md#菜单状态直接保存)。

## 平台和租户的优先级

平台提供默认完整结构；租户只保存明确调整过的同级列表顺序，以及跨组时被移动项的父级。一级顺序调整不冻结各组二级，组内重排不冻结其他项的父级。平台后续变化继续作用于未覆盖部分。2026-09-29的[073@1.0.0](../docs/sdd/SPEC-SUIYIN-ADMIN-073/1.0.0/spec.md)只将原一级话术位置迁为「工具管理 → 话术管理」，保留原话术隐藏/权限及其他菜单的合法覆盖；艺星另有辅助线子项，工具父级按可见子项显示，不因迁移复活隐藏话术或扩大租户能力。

已保存顺序中的现存成员保持相对位置，新进入成员按平台有效顺序追加，缺失成员不生成节点。目标父级失效时保留覆盖、提示并暂用当前平台有效父级，无平台定义时用租户原始父级；恢复后重新应用覆盖。

平台当前祖先链的隐藏、删除及原有权限独立生效。把菜单从平台隐藏的父级移到别处不能解除隐藏；平台显示也不能新增本租户页面或解除本租户独立隐藏。可见导航由同一完整菜单树过滤得到，隐藏项仍留在库存。

## 保存、撤销与异常

一次有效移动把树、局部覆盖和操作记录作为同一成功状态保存；写入失败时全部保持上次成功结果，不通知其他窗口半成品。撤销仅回退最近移动并恢复该次覆盖，撤销失败保留重试机会。刷新、后续菜单数据修改以及外部相关变更会使旧撤销失效；展开、滚动、打开后取消弹窗不会。

非法落点、原位、表外松手、Escape、失焦和pointercancel不保存、不记操作。只读或不可编辑项不能拖动；历史深层分支保留并禁用相关拖动。重复身份或路由保留原数据并说明配置冲突，当前原型暂禁整树拖动；安全导航仍沿用平台限制及既有租户覆盖。错误、加载、空态不造菜单。

旧版数字排序、隐藏和权限设置接续为初始有效状态，不自动当作新拖动意图。外部菜单变更到达时取消未提交拖动、清理旧撤销并载入最新结构，避免用旧快照覆盖新设置。

## 交付和能力边界

原型仅保存同浏览器同源的本地演示状态，不接真实后台、不承诺跨设备共享。生产实现需通过正式工程流程完成持久化、权限、并发与失败一致性，并以版本化Test Contract验收。068限定替代051的普通菜单手工排序和060的普通menu排除、平台无条件排序优先；051/060旧版本包作为不可变历史保留。
