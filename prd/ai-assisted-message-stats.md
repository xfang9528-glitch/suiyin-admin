# AI 辅助消息使用统计 PRD

> Source Contract：`SPEC-SUIYIN-ADMIN-009@1.0.0`
>
> 状态：房总已批准，原型已实施
> 更新日期：2026-08-05

## 1. 用户问题

管理者目前只能看到销售消息总量，无法分清哪些消息由 AI 直接发送、哪些是在参考 AI 后发送、哪些完全手动录入，因此看不清团队真实的 AI 使用量，也没有后续评估客户等级和到店变化所需的可信使用基线。

## 2. 完成后变化

管理者可以沿用话术统计的操作习惯，按日期、销售账号或部门查看 AI 直发、AI 参考和手动录入消息数，以及 AI 辅助合计与占比。统计只从功能上线后开始；所有租户都有同一页面，没有本租户数据时正常显示空态。

## 3. 范围

### 3.1 本期包含

- 数据展示新增「AI辅助统计」入口，位于「话术统计」之后。
- 今天 / 昨天 / 本周 / 本月、自定义起止日。
- 按销售账号 / 按部门维度。
- 部门筛选；账号维度支持销售账号 / 姓名关键词。
- AI 直发、AI 参考、手动录入、AI 辅助合计 / 占比。
- 10 / 20 / 50 条分页，默认 20 条。
- 加载、空态、失败重试、无权限、非法日期和横向溢出。
- 全部租户显示完整页面；成都艺星首期有数据，其他租户没有数据时显示普通空态。

### 3.2 本期不包含

- 上线前历史消息追溯、估算或补标。
- 未标记数、标签覆盖率。
- 客户等级迁移、D→A、到店率、成交率或任何 AI 因果结论。
- 消息正文、AI 建议原文、销售修改内容或客户身份下钻。
- 导出、趋势图、奖惩排行、自动提醒或目标阈值。

## 4. 统计口径

1. 合格对象是当前租户、当前日期范围内，销售在单聊中发出的文本消息。
2. 每条合格消息只按已有来源标签互斥计入 AI 直发、AI 参考或手动录入之一，不根据正文推断。
3. `sent_at` 早于当前环境实际上线时刻的消息完全不计；查询范围整体早于上线时显示普通空态。
4. AI 辅助合计 = AI 直发 + AI 参考。
5. AI 辅助率 = AI 辅助合计 ÷（AI 直发 + AI 参考 + 手动录入）；分母为 0 时显示「—」。
6. 部门三类数量等于成员账号数量之和；部门占比必须用汇总后的分子 / 分母重算，不能平均账号百分比。
7. 默认按 AI 辅助合计降序。

## 5. 交互与默认值

| 项目 | 默认 / 行为 |
|---|---|
| 日期 | 本月首日至今天；Asia/Shanghai 自然日包含 |
| 维度 | 按销售账号 |
| 部门 | 全部部门 |
| 账号关键词 | 空；仅账号维度显示 |
| 分页 | 20 条/页，可选 10 / 20 / 50 |
| 新查询 | 回到第 1 页 |
| 重置 | 恢复以上默认值 |
| 非法日期 | 提示「开始日期不能晚于结束日期」，不刷新旧结果 |

## 6. 表格

### 6.1 按销售账号

`# / 销售账号 / 所属部门 / AI直发 / AI参考 / 手动录入 / AI辅助合计 / 占比`

### 6.2 按部门

`# / 部门 / 账号数 / AI直发 / AI参考 / 手动录入 / AI辅助合计 / 占比`

## 7. 状态与租户

- 有数据：展示排序后的统计表和分页。
- 无数据：筛选栏、表头和分页结构保留，显示「当前筛选范围内暂无数据」。
- 加载失败：显示「统计数据加载失败，请重试」和重试动作。
- 无权限：显示「你暂无查看 AI 辅助统计的权限」。
- 其他租户：不得显示「未接入」，不得借用成都艺星 mock。
- 上线前区间：与合法无结果一致，走普通空态。

## 8. 效果分析边界

本页只描述 AI 使用构成，不等同于 AI 帮助客户升 A、提升到店率或成交率。后续效果分析必须另建规格，明确样本归属、观察窗、基线 / 对照、等级与到店权威数据、覆盖门槛和归因口径。
