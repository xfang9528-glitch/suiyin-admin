# 平台菜单拖动与全租户导航联动

平台拖动合同：[060@1.1.0](../docs/sdd/SPEC-SUIYIN-ADMIN-060/1.1.0/spec.md)；普通menu范围和平台/租户优先级以[068@1.0.0](../docs/sdd/SPEC-SUIYIN-ADMIN-068/1.0.0/spec.md)为当前规则。060已发布快照保留历史，其普通menu排除和平台无条件顺序覆盖已由068限定替代。提出环境佰智德三，提出人房昕；平台为 PC 管理页。

管理者面对长菜单列表时，无需逐条填写排序号：拖动一级携带全部二级，二级可组内重排或移入另一个一级，各租户侧栏按当前平台默认结构和自己的明确调整即时更新。

- 保留九列表格、既有操作及固定表头。名称左侧独立手柄；顺序自动编号，新增默认追加同层末尾。
- 不允许一级嵌套、二级升级或拖出三级；旧更深层数据保留、相关拖动禁用。长表提供插入线、目标文案、悬停展开及边缘滚动；键盘和触控可操作。
- 落下保存，可撤销最近一次移动；取消/原位无变化，失败还原且明确重试。成功保存及重新载入有可见提示。
- 平台顺序、二级归属作为全部租户的默认结构；租户明确调整过的同级列表保留本租户顺序，仅被跨组移动项保留父级，其余继续跟平台。平台当前祖先链的隐藏与删除始终有效；即使租户已将菜单移出其平台父级，也不能绕过该父级隐藏。平台显示不解除租户独立隐藏，不扩充原有页面权限。名称相同但路由不同的项分别匹配。
- 当前页及已开其他租户页无需整页重载；刷新、重新开页及切换租户读取同一配置。仍可见页面保留内容状态，菜单折叠、滚动、侧栏和页签恢复。
- 原型使用当前浏览器同源本地记忆；已有旧排序/隐藏设置直接接续。生产实施需由服务端保存并保证跨会话/全租户读取，不能把 localStorage 当作最终存储。

只增加原型交互与合同，不改变同步、复制、增量更新按钮规则，不写真实后台。工程全部适用租户以生产注册表及权限为准，15 个原型租户不是白名单。
