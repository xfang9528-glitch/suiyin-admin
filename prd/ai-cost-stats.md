# AI费用统计产品说明

更新：2026-09-20。行为合同为 [SPEC-SUIYIN-ADMIN-058@1.2.0](../docs/sdd/SPEC-SUIYIN-ADMIN-058/1.2.0/spec.md)，依赖 051@1.1.0、053@1.0.2、055@1.1.0。本文汇总当前已批准行为，计次、金额、趋势与模型的规则仍以 R001–R019 及对应 AC 为准。

## 用户结果与范围

客户管理员可以按单日或日期范围，查看每类 AI 分析的次数、费用、专属模型与每天的变化。业务分析次数、模型请求、消息采用次数与客户费用分别定义，不能用一种数量代替其他指标。

入口为「AI管理 → AI费用统计」，稳定路由 aiCostStats。当前 13 个已有 AI 管理父级的租户同步侧栏、菜单管理及已有平台定义：yestar-sz、yestar、yestar-bj、yestar-gz、yestar-hz、yestar-jx、bzds、mengzhua、crrm、yzhb、ykjl、ruixi-kh-xiaowen、rxxz。锦帛美学（jbfs）、厚全鸡蛋（hqjd）保持既有菜单；不补父级或扩大权限。隐藏父级、显式隐藏页和无权限状态都不能通过本地直链绕过。

## 日期、表格与项目

筛选仅含统计时间：单日/范围、日期输入与日历、今天/昨天/前天、搜索、重置。范围是含首尾的 Asia/Shanghai 自然日。输入和模式只改草稿；搜索提交后，已应用日期、图表、表格与合计使用同一结果。快捷日立即查询并保留模式；重置回今天单日、分析次数和全部已列项目。非法日期不覆盖旧结果；Escape 或外部点击取消未完成日历选择。

表格固定为分析项目、专属模型、分析次数、费用（元）四列，表尾保留合计。项目顺序为客户标签、客户画像、AI上下文整理、沟通进度分析、AI辅助回复。其他候选场景未确认费用归属，不直接独立列项或重复累计。没有部门、员工、账号、模型筛选、导出、充值、调价或任务明细入口。

分析次数按租户内独立业务任务首次成功完成计 1；同任务自动重试、重复回调不重复计，失败不新增成功次数。先全记录去重，再按首次成功自然日筛选；无法提供可信业务任务 ID 时次数待确认。费用根据独立客户费用记录的发生日期汇总，失败任务可能仍有已确认费用，跨日请求的费用不随成功次数搬日。

## 金额与完整性

客户费用与供应商采购成本分开。供应商成本、内部利润、未确认倍率或统一单价不得转成对客金额；示例金额不表示实际扣费或报价。金额内部按整数微元累加，展示人民币元；已确认零显示 0.00，正数小于 0.01 元显示“小于0.01”，未知显示“费用待确认”。

只有金额、项目归类和所选日期全部完整才可表示完整总计。部分金额已知时说明已确认费用及待确认项目；项目覆盖未核实时用“已列项目费用”。已知未归类费用单独披露，不消失或重复计入五类。查询部分缺日期时保留已覆盖部分并标出缺失范围；缺样本不按 0 次或 0 元处理。

## 每日与分类趋势

趋势图位于表格上方，默认“分析次数 / 全部已列项目”，可切换费用或单个分析项目，每次一条折线。类别仅影响图表，表格始终保留五类及合计；图表与表格共用已提交日期和同一批底层记录。次数轴为整数，费用轴单位为元。

相邻自然日的完整点用实线连接；已知零绘零点。缺日期、全部未知、未启用且无调用不补零，保留对应日期位置并断线。部分已知使用孤立空心点，说明其只是已确认部分，不连接相邻实线。单日只显示一个点，提示可选择日期范围查看多日趋势，不生成邻近日期或小时数据。鼠标和键盘均可查看日期、类别、值或未知状态。

## 82天演示样本与专属模型

固定样本覆盖 2026-07-01 至 2026-09-20，共 82 天；各租户和五项目有稳定可复现的量级与周内波动，刷新不改变样本。日期默认与重置仍取上海今天，因此固定覆盖外的今天显示缺样本；不让样本日期随系统时钟滚动。

| 分析项目 | 深圳演示模型 | 萌爪、佰智德三演示模型 |
|---|---|---|
| 客户标签 | 星瞳 (StarInsight)·客户标签洞察模型 | 碎银·客户标签洞察模型 |
| 客户画像 | 星鉴 (StarLens)·客户画像超智模型 | 碎银·客户画像超智模型 |
| AI上下文整理 | 星鉴 (StarLens)·客户画像超智模型 | 碎银·客户画像超智模型 |
| 沟通进度分析 | 星程 (StarPath)·客户沟通进度分析模型 | 碎银·客户沟通进度分析模型 |
| AI辅助回复 | 星语 (StarTalk)·图灵聊天辅助模型 | 碎银·图灵聊天辅助模型 |

模型列以品牌名为主、用途为辅，单类图表及每日提示同步模型。名称绑定本批合成事件与费用记录，不用当前配置覆盖查询期历史；多个模型并列，有调用但缺模型时待确认。无调用可以显示明确标识的演示配置及无调用/未启用状态；全部类别显示多模型，不强行归入一个模型。画像和上下文共用模型不会增加分析次数或费用。

深圳、萌爪、佰智德三名称来自各自已采配置；其他 10 个租户的配置来自佰智德三参考样本，明确显示“演示配置”。没有独立版本证据时不增加版本，不暗示基座自研、客户独占或已经专门训练。名称及合成记录不证明 82 天实际历史调用。

## 状态与工程边界

正常、全零、部分待确认、未启用、缺样本、加载失败和无权限分别表达。加载禁用重复提交，失败时不展示可误读的旧合计；重试使用已应用日期。表头在当前表格滚动区域内冻结，金额右对齐；窄窗横向滚动、焦点、日历浮层与图表提示保持可用。

本原型只读取本地合成记录，无真实扣费或业务写入。正式计次字段、对客收费来源、失败重试费用、账务日期及延迟继续由 Q002–Q004 和工程交付合同核实。AI辅助统计仍执行 009@1.0.0 的销售消息来源定义，不用其直发/参考数量换算费用。

实际本地证据见 [058 验收记录](../docs/sdd/SPEC-SUIYIN-ADMIN-058/1.2.0/verification.md)；工程执行见 [Issue Handoff](../docs/sdd/SPEC-SUIYIN-ADMIN-058/1.2.0/issue-handoff.md) 与 [Test Contract](../docs/sdd/SPEC-SUIYIN-ADMIN-058/1.2.0/test-contract.md)。房昕在佰智德三环境提出、安排陈宣宇承接管理页工程实现；真实 Issue 编号、状态、生产结果及发布回执以实际建单和验收记录为准。原型推送不等于生产上线，不更新开发进度表。
