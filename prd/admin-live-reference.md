# 管理后台真实界面对照与完整内容 PRD

版本：2026-09-19；行为合同：[SPEC-SUIYIN-ADMIN-051@1.1.0](../docs/sdd/SPEC-SUIYIN-ADMIN-051/1.1.0/spec.md)。本文件是该合同的产品说明，不另立规则。

## 用户结果与范围

房总及评审者可以在既有原型中进入对应租户，看到完整内容和可操作样本，并核对下拉、弹窗、编辑及取消结果。此前仅有导航、空表或通用表格的页面不足以检查真实 UX；本轮按领域页面结构完善。

范围为十五租户：佰智德三、锦帛美学、萌爪、诚如风险管理事务所、厚全鸡蛋、柚子烘焙；瑞熙小刘、小温、小周；艺星成都、深圳、北京、广州、杭州、嘉兴。截图划除项、碎银私域和不可访问环境排除。导航库存为 737 个租户路由组合、83 种路由；可见菜单依各租户实际显示配置决定，并不承诺各租户看到相同入口。

## 菜单纠偏

原型与原站必须使用同租户、同视口对照。深圳和成都菜单可见性不同，不能把成都右图的隐藏项直接当深圳应隐藏项。重新采样深圳、成都、广州、杭州、嘉兴配置，其他租户保留各自已有样本。

普通菜单具六个物理列：菜单名称、超级权限、菜单状态、排序、无标题弹性列、操作。空白弹性列不填破折号。权限使用开关，层级缩进与展开箭头真实存在，操作固定右侧，编辑/删除/记录依原站尺寸布局。普通编辑名称不可改、三列布局，平台编辑两列布局。排序允许负数，窄输入保持数值可读性。修改只写本地，真实后台只读。

## Mock 与统计口径

默认应有数据的页面使用可操作样本；原站有意空字段与真实无结果不强行填充。先用本租户脱敏采样，缺少可用明细时使用标明来源的参考或合成样本。样本分布、行数和界面覆盖见验收摘要，不能冒充本租户实时记录。

AI 辅助统计继承 009@1.0.0：单聊文本、来源互斥、上线后累计，合计与占比按汇总重算，不推导效果。当前原型默认 Mock 非空取代旧“非成都固定空态”；筛选无结果仍有业务空态。工作账号触达统计继承 042@1.0.0：账号逐行，成功消息数与去重人数分开，不把 AI 统计的范围套入触达。

## 状态与验收

输入校验、无结果、加载失败、重试、禁用选项、取消、Escape、焦点恢复、长表/下拉溢出应有明确反馈。所有修改按 tenant + route 隔离并可刷新读回。危险操作指明对象并确认；不以 Toast 冒充线上成功。

数据校验、操作验收、视觉对照分别给结论。菜单 54 项与关键流程 22 项通过；737 项为数据/静态入口验证，不能证明全部页面像素一致。已知未逐像素对照的路由、失败页面及资源缺口见 [验收记录](../docs/verification/admin-live-reference.md)。
