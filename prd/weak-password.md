# 弱口令强制改密（管理后台）

行为真源：[WEAK-PASSWORD-4746@0.1.0](../docs/sdd/SPEC-SUIYIN-ADMIN-WEAK-PASSWORD-4746/0.1.0/spec.md)。后端单 suiyin-go#4746，前端单 [suiyin-admin#557](https://github.com/PetWebOrg/suiyin-admin/issues/557)。方案定稿 `erio-mind/decisions/design/4746-weak-password-design-v3/final.md`，设计稿同目录 `mockups/admin.html`。

## 强制改密页

登录返回 `passwordStatus.required=true` 时不进首页，停在强制改密页。管理后台在提示期（warn）就强制（D2），和 enforced 一样。页面就是登录页「忘记密码」三步流程：品牌卡片、绿色标题「修改密码」、步骤条「校验身份 / 设置密码 / 修改成功」、胶囊输入框和主按钮。左上返回条改为「退出登录」。出口只有两个：改密成功、退出登录。

- 原因说明用 Shell 的黄色提示条 `.source-index-alert`：reason 为 security 时显示「为保障账号安全，管理员账号需要修改一次密码」，其他 reason（default、weak、不认识的值）显示通用文案「你的密码过于简单，容易被他人登录，请修改后继续使用」。
- 刚登录就进入：旧密码已在内存里（只放内存，不落 storage），从第 2 步开始，第 1 步显示已完成。
- 旧会话收到 HTTP 428（42800）进入：内存里没有旧密码，从第 1 步开始。手机号只读并遮罩，输入旧密码后点「下一步」。
- 第 2 步常驻提示「请不要和同事使用同一个密码」，按钮为「确认修改」。

## 强度规则与服务端报错

前端按顺序校验 6 条规则，只显示第一条没通过的：可见 ASCII、8–20 位、同时有字母和数字、不含手机号后 6 位、不等于旧密码、两次一致。前端不内置弱口令名单，以服务端返回的 40020 为准。

| 返回 | 表现 |
|---|---|
| 40020 | 文案标在新密码框下（三种：密码太常见 / 不能是默认密码或手机号 / 不能与以前用过的相同） |
| code 401 | 回第 1 步，旧密码框标红「旧密码错误，或密码刚在其他设备上修改过」，清掉内存里的旧密码；新密码草稿保留 |
| 42900 | 按钮用「登录中...」同款禁用写法，显示「请 n 秒后重试」，上方黄色话术同步倒计时；倒计时结束后要手动再点，不自动重发 |
| 成功 | 第 3 步 `.success-icon`，「密码修改成功，正在进入系统 3s」，或点「进入系统」 |
| 50020 | 回登录页，提示「密码已修改，请用新密码登录」 |
| 网络错误 / 5xx | 不静默登录，回登录页，提示「密码可能已修改成功，请用新密码登录」 |
| 旧凭证 401 `password_changed` | 回登录页，提示「密码已被修改，请向使用该账号的同事获取新密码」 |

报错红用后台已有的 Element 错误红 `#f56c6c`。提示用后台内容页同款 `#toast`（顶部居中深色）。

## 登录被锁（42910）

登录页用 `#toast` 显示三种锁的文案（N 由服务端给，原型示范 15）：账号锁、网络锁、登录请求较多。

## 长度上限

登录框、忘记密码和强制改密的密码框 `maxlength` 都从 16 改为 20。原占位符「6-16位字母加数字」和新规则冲突，登录框改为「请输入密码」，新密码框改为「请输入新密码（8-20位，含字母和数字）」。忘记密码流程本身的步骤和跳转不变。

## 重置密码确认

碎银账号页点「重置密码」不再弹「新密码」输入框，改用菜单管理「确认删除菜单?」同款确认框 `.menu-delete-dialog`（黄色感叹号，取消 / 确定）：

> 确认重置「姓名」的登录密码？
> 重置后新密码为该账号手机号后 6 位，对方下次登录必须先修改密码；此操作会记录审计日志

点确定后 `#toast` 显示「重置成功，对方下次登录需先修改密码」。旧页 `sales_v1.0.html` 的确认文案同步修改，不再提短信。

## 演示入口

沿用本仓 `qa=1` 加状态参数的写法（同 `usageState`、`costState`）：

| 状态 | 地址 |
|---|---|
| 提示期 / 强制期，登录后直达第 2 步 | `prototype/login_v1.0.html?qa=1&pwState=warn`（或 `enforced`），点「登 录」 |
| 管理员（security） | 上一行加 `&pwReason=security` |
| 被接口拦截（428）进入第 1 步 | `prototype/login_v1.0.html?qa=1&pwState=428` |
| 40020 / 旧密码错误 / 42900 / 50020 / 网络错误 | 在前两行地址上加 `&pwResult=40020`（`40020-default`、`40020-used`）、`401`、`42900`、`50020`、`neterr`（或 `5xx`）；错误只返回一次，再提交按成功处理。42900 可加 `&retryAfterSec=n` |
| 401 password_changed | `prototype/login_v1.0.html?qa=1&pwState=password_changed` |
| 42910 三种锁 | `prototype/login_v1.0.html?qa=1&pwState=lock-account`（`lock-ip`、`lock-gate`），点「登 录」 |
| 重置密码确认 | `prototype/_shell.html?tenant=yestar-sz&page=salesManage`，点任一行「重置密码」 |

本原型只演示前端状态，不接真实认证。旧密码在原型里是内存里的明文变量，生产是内存里的 sha256，不落 storage。
