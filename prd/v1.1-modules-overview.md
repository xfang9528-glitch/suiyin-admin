## 1. 本轮目标

按艺星医美生产后台 1:1 对齐，铺出全部 13 个一级菜单 + 35 个子菜单的原型页（共 48 项菜单，对应 38 个独立页面文件 + 4 个 v1 对齐页）。

每页字段、筛选器、状态枚举、操作按钮均通过 Claude in Chrome 接入艺星生产后台 (https://yestar.wecarepet.com/admin/) 抓取真实 DOM 后实现。

## 3. 通用约定

### 3.1 真实数据脱敏边界
- 用真实：销售/院长姓名、群名、产品名、医美科室、渠道、案例标题
- 全脱敏：手机号 `138****1234`、身份证、银行卡 — 严禁明文进 git
- 不抄图：客户头像 / 真实截图 — 用渐变占位代替

### 3.2 通用列表页范式
- 顶部筛选栏 56px：输入 + 下拉 + 日期范围 + 查询/重置 + 右侧操作按钮
- 表格区：粘性表头 + 横向滚动（min-width 触发）+ 行 hover 高亮
- 底部分页器固定 48px：总数 + 页大小 + 页码

### 3.3 弹窗范式（_edit_modal.js）
- 配置驱动，字段类型：text/number/select/textarea/switch/radio/tags/image/rich
- 默认 560px 宽，复杂场景 720-1080px
- 头部标题 + 关闭 ✕，body 表单，footer 取消 + 确认（确认绿色）
- 必填字段前 `*` 红色

### 3.4 视觉风格（公众号克制版）
- Header：白底 + 灰边 + 绿色 ◉ logo + 浅绿"管理后台"小标签
- 通知图标：右上 🔔 + 红色数字徽章
- 主按钮：实心微信绿（仅创建/添加/确认等关键动作）
- 次按钮：白底浅灰边 + 灰字（默认），hover 变绿
- 链接按钮：公众号蓝 #576b95，不再用 #3370ff
- 状态徽章：浅色背景 + 中和色文字（柔和饱和度，参考公众号配色）
